# Notes for the re-cut of #39287 (node:test t.signal, signal option, subtest sweep)

This branch holds the unpushed rework of #39287 (commit 50428c06ae) and its PR body draft. It is not ready. Re-cut it on top of #48273, with the sweep as its own commit. Findings of the review of this head:

Regressions against main
- A replaced `--retry` attempt must not lose its mock reset or its `t.after` hooks. #48273 keeps an attempt that bun:test ended in its body on its node. Decide what cancel state does there (see #43803).
- `suite.started = true` in `scheduleSuiteSubtest` is read by module-level `before()`. Two shapes in an async inline `describe()` break. Use another marker.
- The sweep only knows `TestNode` children. A `t.before()` hook link or a skip directive link queued behind a running subtest still runs after the parent is over. Return early in those links when the node is finished.
- `settledOrNever()` returns one shared never-settling promise. Every cancelled queued subtest leaves a reaction on it. Return a new promise for each.
- A verdict that arrives after bun:test's own timeout ended the test goes through `done(error)` and fails the test that runs then. The `signal` option is a new source of such verdicts. Do not change the channel to a rejected promise: that breaks the `BUN_TEST_DRAIN_EVENT_LOOP` row of `test/cli/test/bun-test.test.ts` (#44833). The rule belongs in bun:test (`on_done_error`, see #48142 and #39112).
- Fixture 35 must keep its first `AbortController` reachable and call `Bun.gc(true)` before each reading.

Node parity of the new surface
- The plan wait timeout (`t.plan(n, { wait: ms })`) must go through `cancel()` with `failureType: 'testTimeoutFailure'`.
- The end-of-test abort fires before the verdict of a failing `afterEach` or `t.after` hook is written. Set `passed` and `error` in the hook catch blocks.
- A queued subtest declared `{ signal: t.signal }` must be `testAborted`, not `cancelledByParent`: add its listener at `t.test()` time.
- A swept subtest keeps its mocks through its own hooks. Reset them and remove its listener in the sweep. One finisher for every exit.
- Report every cancelled child from the sweep, in order, for `run()`.
- A subtest that needs only microtasks can be cancelled where Node and main pass it (the parent throws, no hooks). Give stragglers one macrotask before the sweep, as #39286 does, or move the verdict part to #39286.
- `park()` must only accept a promise that it can reject safely, enforced in code.

Tests and body
- Fixture 31 needs gates so that the order is the same as in Node, then compare in order.
- Pin the clauses that mutation testing found unpinned (the two guards that stop a cancelled subtest from running its body first).
- Node asserts this behaviour in-process in `test-runner-misc.js` and `test-runner-run.mjs`. Cite and carry those cases.
- Say that no user reported this. Describe the late verdict truthfully. The docs sentence must also cover `timeout >= 5000`.
- Measured on this head: `TestNode` 320 B (main 224 B), +3,596 instructions per plain test with the JIT off, 2 fewer heap cells per test.
- The order against #34515 is a maintainer decision (22 conflict hunks in `src/js/node/test.ts`).
