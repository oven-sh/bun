Bun turns a TypeScript or JavaScript program into one executable file. It runs on machines that don't have Bun installed.

```ts cli.ts icon="/icons/typescript.svg"
console.log("Hello world!");
```

```bash terminal icon="terminal"
bun build --compile ./cli.ts --outfile mycli
./mycli
```

```txt
Hello world!
```

## Two ways to compile

|                      | `bun build --compile`         | `bun compile`             |
| -------------------- | ----------------------------- | ------------------------- |
| The executable holds | Your bundled JavaScript       | Machine code              |
| It runs              | With the JIT, like `bun run`  | Without a JIT             |
| TypeScript types     | Removed, never checked        | Checked, then used        |
| Builds for           | Any platform, with `--target` | The platform you build on |
| Status               | Stable                        | Experimental              |

`bun build --compile` runs nearly everything that `bun run` runs. With `bun compile`, which is short for `bun build --compile --aot`, your program starts faster, and [a few things differ from `bun run`](/compiler/compatibility). A large application uses less memory, and a tiny program uses about as much as without AoT.
