Use the [Svelte CLI](https://svelte.dev/docs/cli/overview) to scaffold a new SvelteKit project.

```sh terminal icon="terminal"
bunx sv create my-app --template demo --types ts --add sveltekit-adapter="adapter:bun" --install bun
```

---

To start the development server:
```sh terminal icon="terminal"
cd my-app

# via node runtime
bun run dev

# via bun runtime
bun --bun run dev
```

```txt
  $ vite dev
  Forced re-optimization of dependencies

    VITE v5.4.10  ready in 424 ms

    ➜  Local:   http://localhost:5173/
    ➜  Network: use --host to expose
    ➜  press h + enter to show help
```

---

Visit [http://localhost:5173](http://localhost:5173/) in a browser to see the template app.

---

Edit and save `src/routes/+page.svelte` and the dev server hot-reloads your changes in the browser.

---

To build a production bundle:

```sh terminal icon="terminal"
bun run --bun build
```


---

Then start the production server with `bun ./build/index.js`. It listens on port `3000` by default; set the `PORT` environment variable to change it.

```sh terminal icon="terminal"
bun ./build
```

```txt
Listening on http://0.0.0.0:3000/
```

For more information, see the [Svelte documentation](https://svelte.dev/docs/kit/adapter-bun).
