---
title: Bail early with the Bun test runner
sidebarTitle: Bail early
mode: center
---

Use the `--bail` flag to abort a test run after the first failure, so a continuous integration run fails as early as possible.

```sh terminal icon="terminal"
bun test --bail
```

---

To bail after a certain number of failures, pass a number after the flag.

```sh terminal icon="terminal"
# bail after 10 failures
bun test --bail=10
```

---

When the run bails out, Bun still runs the `afterEach` and `afterAll` hooks of the tests and `describe` blocks that started. Then Bun prints the summary. The summary has the `--seed` if `--randomize` or `describe.shuffle` set the order.
