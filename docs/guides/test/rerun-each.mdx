title: Re-run tests multiple times with the Bun test runner
sidebarTitle: Re-run tests

---

The `--rerun-each` flag runs every test multiple times. Use it to find flaky or non-deterministic tests.

```sh terminal icon="terminal"
# re-run each test 10 times
bun test --rerun-each 10
```

Each run loads the test file again. What the file imports stays loaded, except a module that registered hooks, tests, stubs, spies or module mocks when it was imported. Bun evaluates that module again for each run. See [Rerun tests](/test#rerun-tests).
