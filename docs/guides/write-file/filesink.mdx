Bun provides an API for incrementally writing to a file. Use it for large files, or when writing to a file over a long period of time.

Call `.writer()` on a `BunFile` to retrieve a `FileSink` instance. The `FileSink` buffers data. Call `.flush()` to write the buffer to disk. You can write & flush many times.

```ts
const file = Bun.file("/path/to/file.txt");
const writer = file.writer();

await writer.write("lorem");
await writer.write("ipsum");
await writer.write("dolor");

await writer.flush();

// continue writing & flushing
```

---

`.write()`, `.flush()`, and `.end()` return a `number` when the write completes right away. They return a `Promise<number>` while a write is pending, for example under backpressure. `await` the result to handle both cases.

---

The `.write()` method accepts strings or binary data.

```ts
await writer.write("hello");
await writer.write(Buffer.from("there"));
await writer.write(new Uint8Array([0, 255, 128]));
await writer.flush();
```

---

The `FileSink` also auto-flushes when its internal buffer is full.

---

When you're done writing, call `.end()` to flush the buffer and close the file. `await` it so the data lands before your code continues or the process exits.

```ts
await writer.end();
```
