---
title: "bun:test/consistent-test-filename"
description: "Require test files to follow one naming pattern"
---

When some test files are named `user.test.ts` and others `user.spec.ts`, a glob or a search written for one name misses the other. This rule picks one. By default a file that ends in `.test` or `.spec` plus `.js`, `.jsx`, `.ts` or `.tsx` is a test file, and its name has to use `.test`.

Only files that import from `"bun:test"` are checked.

## Examples

Reported, in a file named `src/user.spec.ts`:

{/* bad {"filename": "src/user.spec.ts"} */}

```ts
import { expect, test } from "bun:test";

test("has a name", () => {
  expect(loadUser().name).toBe("Ada");
});
```

Not reported, in a file named `src/user.test.ts`:

{/* good {"filename": "src/user.test.ts"} */}

```ts
import { expect, test } from "bun:test";

test("has a name", () => {
  expect(loadUser().name).toBe("Ada");
});
```

## Options

Both options are regular expressions, written as strings and tested against the file's path. `/pattern/` works too. Flags after the last slash are ignored.

| Option           | Default                      | What it does                                             |
| ---------------- | ---------------------------- | -------------------------------------------------------- |
| `pattern`        | `.*\.test\.[tj]sx?$`         | What the path of a test file has to match.               |
| `allTestPattern` | `.*\.(test\|spec)\.[tj]sx?$` | Which files are test files. Other files are not checked. |

```toml bunfig.toml
[lint.rules]
"bun:test/consistent-test-filename" = ["error", { pattern = '.*\.spec\.ts$' }]
```

With that `pattern`, `src/user.test.ts` is reported and `src/user.spec.ts` is not:

{/* bad {"options": [{"pattern": ".*\\.spec\\.ts$"}], "filename": "src/user.test.ts"} */}

```ts
import { test } from "bun:test";

test.todo("has a name");
```

{/* good {"options": [{"pattern": ".*\\.spec\\.ts$"}], "filename": "src/user.spec.ts"} */}

```ts
import { test } from "bun:test";

test.todo("has a name");
```

With `allTestPattern` set to `__tests__`, every file under a `__tests__` directory is a test file. `__tests__/user.ts` is reported because it does not end in `.test.ts`:

{/* bad {"options": [{"allTestPattern": "__tests__"}], "filename": "__tests__/user.ts"} */}

```ts
import { test } from "bun:test";

test.todo("has a name");
```
