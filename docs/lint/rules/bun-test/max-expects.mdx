---
title: "bun:test/max-expects"
description: "Enforce a maximum number of `expect()` calls in a test"
---

A test with many assertions usually checks several things at once. The first `expect` that fails stops the test, so one failure hides the ones after it, and the test's name no longer says what broke.

By default a test can have 5 `expect()` calls. Each call after that is reported.

## Examples

Reported:

{/* bad {"count": 1} */}

```ts
import { expect, test } from "bun:test";

test("creates a user", () => {
  const user = createUser({ name: "Ada", email: "ada@example.com" });
  expect(user.id).toBeGreaterThan(0);
  expect(user.name).toBe("Ada");
  expect(user.email).toBe("ada@example.com");
  expect(user.role).toBe("member");
  expect(user.active).toBe(true);
  expect(user.createdAt).toBeInstanceOf(Date);
});
```

Not reported:

{/* good */}

```ts
import { expect, test } from "bun:test";

test("keeps the name and the email", () => {
  const user = createUser({ name: "Ada", email: "ada@example.com" });
  expect(user).toMatchObject({ name: "Ada", email: "ada@example.com" });
});

test("fills in the defaults", () => {
  const user = createUser({ name: "Ada", email: "ada@example.com" });
  expect(user.id).toBeGreaterThan(0);
  expect(user.role).toBe("member");
  expect(user.active).toBe(true);
  expect(user.createdAt).toBeInstanceOf(Date);
});
```

Calls are counted per function and per block. An `expect` inside a loop or a callback does not add to the count of the test around it:

{/* good {"options": [{"max": 1}]} */}

```ts
import { expect, test } from "bun:test";

test("lists active users", () => {
  const users = listUsers({ active: true });
  expect(users).toHaveLength(2);
  for (const user of users) {
    expect(user.active).toBe(true);
  }
});
```

## Options

| Option | Default | What it does                            |
| ------ | ------- | --------------------------------------- |
| `max`  | `5`     | The number of `expect()` calls allowed. |

```toml bunfig.toml
[lint.rules]
"bun:test/max-expects" = ["error", { max = 2 }]
```

{/* bad {"options": [{"max": 2}], "count": 1} */}

```ts
import { expect, test } from "bun:test";

test("parses a URL", () => {
  const url = parse("https://example.com:8080/docs");
  expect(url.host).toBe("example.com");
  expect(url.port).toBe(8080);
  expect(url.path).toBe("/docs");
});
```
