---
title: "bun:test/no-test-prefixes"
description: "Require `.skip` instead of the `x` prefix"
---

`xit`, `xtest` and `xdescribe` are short names for `it.skip`, `test.skip` and `describe.skip`. One extra letter is easy to miss in a review, and a search for `.skip` does not find it.

`--fix` rewrites `xtest` to `test.skip` if the file already imports `test`. The same goes for `xit` with `it` and `xdescribe` with `describe`.

## Examples

Reported:

{/* bad {"count": 2} */}

```ts
import { expect, xdescribe, xtest } from "bun:test";

xtest("subtracts", () => {
  expect(3 - 1).toBe(2);
});

xdescribe("division", () => {});
```

Not reported:

{/* good */}

```ts
import { describe, expect, test } from "bun:test";

test.skip("subtracts", () => {
  expect(3 - 1).toBe(2);
});

describe.skip("division", () => {});
```

What follows the name is kept. This is reported, and the long form is `it.skip.each`:

{/* bad */}

```ts
import { expect, xit } from "bun:test";

xit.each([1, 2, 3])("%i is positive", n => {
  expect(n).toBeGreaterThan(0);
});
```
