---
title: "bun:test/prefer-describe-function-title"
description: "Require `describe(fn, ...)` instead of a string with the name of an imported function"
---

`describe` takes a function or a class as its title and uses its name. A string that repeats the name of something you import stays behind when the function is renamed, and the test output then names a function that no longer exists.

The rule reports a `describe` title that is a string equal to an imported name, and also `slugify.name`.

`--fix-suggestions` replaces the title with the name, unless the import is type-only.

## Examples

Reported:

{/* bad */}

```ts
import { describe, expect, test } from "bun:test";
import { slugify } from "./slugify";

describe("slugify", () => {
  test("replaces spaces", () => {
    expect(slugify("a b")).toBe("a-b");
  });
});
```

{/* bad */}

```ts
import { describe } from "bun:test";
import { slugify } from "./slugify";

describe(slugify.name, () => {});
```

Not reported:

{/* good */}

```ts
import { describe, expect, test } from "bun:test";
import { slugify } from "./slugify";

describe(slugify, () => {
  test("replaces spaces", () => {
    expect(slugify("a b")).toBe("a-b");
  });
});

describe("slugify with options", () => {});
```
