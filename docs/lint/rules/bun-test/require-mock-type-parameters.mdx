---
title: "bun:test/require-mock-type-parameters"
description: "Require a type parameter on `jest.fn()` and `vi.fn()`"
---

A plain `jest.fn()` stands for a function that takes any arguments and returns anything. TypeScript then accepts `mockReturnValue(42)` for a function that returns a string, and it says nothing when the real function changes and the mock no longer matches it. With a type parameter, the mock is checked like the function it replaces.

A mock with an implementation, such as `jest.fn(() => 1)`, is reported too. `mock()` is not checked, and neither are JavaScript files.

## Examples

Reported:

{/* bad {"count": 2} */}

```ts
import { jest, vi } from "bun:test";

const findUser = jest.fn();
const log = vi.fn((message: string) => {});
```

Not reported:

{/* good */}

```ts
import { jest, mock, vi } from "bun:test";

type User = { name: string };

const findUser = jest.fn<(id: string) => Promise<User>>();
const log = vi.fn<(message: string) => void>(message => {});
const send = mock();
```
