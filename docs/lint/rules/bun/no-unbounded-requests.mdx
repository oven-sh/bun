---
title: "bun/no-unbounded-requests"
description: "Require an axios request to have a `timeout` or a `signal`"
---

By default axios has no timeout. If the server accepts the connection and never answers, the promise never settles, and whatever awaits it hangs. Set `timeout`, or pass a `signal` that ends the request.

The rule looks at `axios()`, `axios.request()`, `axios.create()`, and the methods such as `axios.get()` and `axios.post()`. A `timeout` of `0` or `Infinity` is reported too, because it sets no limit.

## Examples

Reported:

{/* bad {"count": 3} */}

```js
import axios from "axios";

const user = await axios.get(`/users/${id}`);
await axios.post("/users", user, { headers });
const api = axios.create({ baseURL: "https://api.example.com", timeout: 0 });
```

Not reported:

{/* good */}

```js
import axios from "axios";

const user = await axios.get(`/users/${id}`, { timeout: 5000 });
await axios.post("/users", user, { headers, signal: AbortSignal.timeout(5000) });
const api = axios.create({ baseURL: "https://api.example.com", timeout: 5000 });
```

A file that sets a default timeout is not checked:

{/* good */}

```js
import axios from "axios";

axios.defaults.timeout = 5000;

const user = await axios.get(`/users/${id}`);
```

A config with `cancelToken` passes too. A config that is a variable, or that spreads another object, is not checked, because the rule cannot see what is in it. For an instance, the `axios.create()` call is checked and the requests made with it are not.

{/* good */}

```js
import axios from "axios";

await axios.get("/users", requestConfig);
await axios.get("/users", { ...requestConfig, params });

const api = axios.create({ timeout: 5000 });
await api.get("/users");
```

## Options

| Option    | Default | What it does                                                                                                                                                                                       |
| --------- | ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `clients` | `[]`    | More modules that export something you call like `axios`. Each entry is `{ module, names }`: the import specifier and the names of the exports. Without `names`, the default export is the client. |

```toml bunfig.toml
[lint.rules]
"bun/no-unbounded-requests" = ["error", { clients = [{ module = "./http.js", names = ["api"] }] }]
```

{/* bad {"options": [{"clients": [{"module": "./http.js", "names": ["api"]}]}]} */}

```js
import { api } from "./http.js";

const users = await api.get("/users");
```

{/* bad {"options": [{"clients": [{"module": "./http.js"}]}]} */}

```js
import api from "./http.js";

const users = await api.get("/users");
```
