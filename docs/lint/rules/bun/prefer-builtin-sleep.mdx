---
title: "bun/prefer-builtin-sleep"
description: "Prefer `Bun.sleep()` to a promise that only waits for `setTimeout`"
---

`new Promise(resolve => setTimeout(resolve, ms))` takes a moment to read, and all it does is wait. `Bun.sleep(ms)` does the same and says so. `setTimeout(ms)` from `node:timers/promises` does too.

`--fix-suggestions` replaces the promise with `Bun.sleep(ms)`.

## Examples

Reported:

{/* bad */}

```js
await new Promise(resolve => setTimeout(resolve, 500));
```

{/* bad */}

```js
function wait(ms) {
  return new Promise(resolve => {
    setTimeout(() => resolve(), ms);
  });
}
```

Not reported:

{/* good */}

```js
await Bun.sleep(500);
```

{/* good */}

```js
import { setTimeout } from "node:timers/promises";

await setTimeout(500);
```

A promise that does more than wait is not reported. This one resolves with a value:

{/* good */}

```js
const answer = await new Promise(resolve => setTimeout(() => resolve("timed out"), 500));
```

## When not to use it

`Bun.sleep()` only exists in Bun, and `node:timers/promises` does not exist in browsers. Turn the rule off for code that also runs in a browser.
