---
title: "array-callback-return"
description: "Require callbacks of array methods such as `map` and `filter` to return a value"
---

Methods like `map` and `filter` use what the callback returns. If the callback forgets `return`, they get `undefined`: `map` fills the array with `undefined`, and `filter` drops every item. A callback that returns a value on some paths only is reported too.

The rule checks a function passed directly to `every`, `filter`, `find`, `findIndex`, `findLast`, `findLastIndex`, `flatMap`, `map`, `reduce`, `reduceRight`, `some`, `sort`, `toSorted`, `Array.from` or `Array.fromAsync`.

## Examples

Reported:

{/* bad */}

```js
const names = users.map(user => {
  user.name.trim();
});
```

{/* bad */}

```js
const adults = users.filter(user => {
  if (user.age >= 18) {
    return true;
  }
});
```

Not reported:

{/* good */}

```js
const names = users.map(user => {
  return user.name.trim();
});

const adults = users.filter(user => user.age >= 18);
```

## Options

| Option          | Default | What it does                                                                                                      |
| --------------- | ------- | ----------------------------------------------------------------------------------------------------------------- |
| `allowImplicit` | `false` | Allow `return;` without a value as a way to return `undefined`.                                                   |
| `checkForEach`  | `false` | Also check `forEach`, the other way around: report a callback that returns a value, because `forEach` ignores it. |
| `allowVoid`     | `false` | With `checkForEach`, allow a returned value that starts with `void`.                                              |

{/* good {"options": [{"allowImplicit": true}]} */}

```js
const first = users.find(user => {
  if (!user.active) {
    return;
  }
  return user.admin;
});
```

{/* bad {"options": [{"checkForEach": true}]} */}

```js
users.forEach(user => save(user));
```

{/* good {"options": [{"checkForEach": true}]} */}

```js
users.forEach(user => {
  save(user);
});
```

{/* good {"options": [{"checkForEach": true, "allowVoid": true}]} */}

```js
users.forEach(user => void save(user));
```
