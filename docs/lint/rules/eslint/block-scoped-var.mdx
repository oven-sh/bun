---
title: "block-scoped-var"
description: "Disallow using a `var` outside the block it is declared in"
---

A `var` declared inside an `if`, a loop or a `switch` is visible in the whole function. Code after the block can read it, and gets `undefined` when the block did not run. This rule reports every use of a `var` outside the block that declares it, as if it were a `let`.

## Examples

Reported:

{/* bad */}

```js
function label(user) {
  if (user.admin) {
    var prefix = "Admin: ";
  }
  return prefix + user.name; // "undefinedAda" for everyone else
}
```

{/* bad */}

```js
function indexOfFirstEmpty(items) {
  for (var i = 0; i < items.length; i++) {
    if (!items[i]) break;
  }
  return i;
}
```

Not reported:

{/* good */}

```js
function label(user) {
  var prefix = "";
  if (user.admin) {
    prefix = "Admin: ";
  }
  return prefix + user.name;
}
```

## When not to use it

If `no-var` is on, there is no `var` left to check, and `let` and `const` already behave this way.
