---
title: "class-methods-use-this"
description: "Require class methods to use `this`"
---

A method that never touches `this` does not need an instance. Callers still have to create one to reach it. Make it `static`, or move it out of the class as a plain function.

The rule checks methods, getters, setters, and fields that hold a function. Constructors and static members are not checked. Using `super` counts as using `this`.

## Examples

Reported:

{/* bad */}

```js
class Cart {
  formatPrice(cents) {
    return "$" + (cents / 100).toFixed(2);
  }
}
```

Not reported:

{/* good */}

```js
class Cart {
  static formatPrice(cents) {
    return "$" + (cents / 100).toFixed(2);
  }

  total() {
    return Cart.formatPrice(this.items.reduce((sum, item) => sum + item.cents, 0));
  }
}
```

## Options

| Option                        | Default | What it does                                                                                                            |
| ----------------------------- | ------- | ----------------------------------------------------------------------------------------------------------------------- |
| `exceptMethods`               | `[]`    | Names of methods that are not checked. Write a private method with its `#`.                                             |
| `enforceForClassFields`       | `true`  | Also check functions that are the value of a field: `format = () => {}`.                                                |
| `ignoreOverrideMethods`       | `false` | Do not check members marked `override` in TypeScript.                                                                   |
| `ignoreClassesWithImplements` | not set | `"all"` skips every member of a class that has an `implements` clause. `"public-fields"` skips only its public members. |

A framework may call a method on the instance whether it uses `this` or not:

{/* good {"options": [{"exceptMethods": ["render", "#label"]}]} */}

```js
class Spinner extends Component {
  render() {
    return "Loading";
  }

  #label() {
    return "Spinner";
  }
}
```

{/* good {"options": [{"enforceForClassFields": false}]} */}

```js
class Cart {
  formatPrice = cents => "$" + (cents / 100).toFixed(2);
}
```

{/* good {"options": [{"ignoreOverrideMethods": true}]} */}

```ts
class Guest extends User {
  override displayName() {
    return "Guest";
  }
}
```

With `"public-fields"`, the interface may ask for `name()`, but it cannot ask for the private `prefix()`:

{/* bad {"options": [{"ignoreClassesWithImplements": "public-fields"}], "count": 1} */}

```ts
class Guest implements Named {
  name() {
    return "Guest";
  }

  private prefix() {
    return "Mx.";
  }
}
```
