---
title: "func-name-matching"
description: "Require a function expression's name to match the variable or property it is assigned to"
---

A function expression can have its own name, different from the variable or property that holds it. Stack traces then show one name while the rest of the code calls the other, so searching for the name from the trace finds no caller.

Only function expressions that have a name are checked. Arrow functions and `function () {}` are never reported.

## Examples

Reported:

{/* bad {"count": 3} */}

```js
const loadUser = function fetchUser(id) {
  return db.users.get(id);
};

api.remove = function destroy(id) {};

const handlers = {
  onSave: function save() {},
};
```

Not reported:

{/* good */}

```js
const loadUser = function loadUser(id) {
  return db.users.get(id);
};

api.remove = function remove(id) {};

const handlers = {
  onSave: function onSave() {},
  onClose: function () {},
};
```

## Options

```toml bunfig.toml
[lint.rules]
func-name-matching = ["error", "always", { considerPropertyDescriptor = true }]
```

The first option is a string. You can leave it out and pass only the object.

| Option               | What it does                     |
| -------------------- | -------------------------------- |
| `"always"` (default) | The two names must be the same.  |
| `"never"`            | The two names must be different. |

| Option                         | Default | What it does                                                                                                          |
| ------------------------------ | ------- | --------------------------------------------------------------------------------------------------------------------- |
| `considerPropertyDescriptor`   | `false` | In a property descriptor, compare the name of the `value` function with the property being defined.                   |
| `includeCommonJSModuleExports` | `false` | Also check `module.exports = function name() {}`. The property is `exports`, so that is the name it is compared with. |

{/* bad {"options": ["never"]} */}

```js
const loadUser = function loadUser(id) {};
```

### `considerPropertyDescriptor`

This applies to `Object.defineProperty`, `Reflect.defineProperty`, `Object.defineProperties` and `Object.create`. Without the option, the function below is compared with its key, `value`, and reported:

{/* bad */}

```js
Object.defineProperty(user, "save", {
  value: function save() {},
});
```

{/* good {"options": ["always", {"considerPropertyDescriptor": true}]} */}

```js
Object.defineProperty(user, "save", {
  value: function save() {},
});
```

### `includeCommonJSModuleExports`

{/* good */}

```js
module.exports = function createServer() {};
```

{/* bad {"options": [{"includeCommonJSModuleExports": true}]} */}

```js
module.exports = function createServer() {};
```
