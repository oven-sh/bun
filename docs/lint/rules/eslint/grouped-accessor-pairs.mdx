---
title: "grouped-accessor-pairs"
description: "Require the getter and setter of a property to be next to each other"
---

When other members sit between the getter and the setter of a property, a reader who finds the getter can miss that there is a setter further down.

The rule checks object literals and classes. In a class, a static pair and an instance pair with the same name are separate.

## Examples

Reported:

{/* bad */}

```js
class User {
  get name() {
    return this.first;
  }
  save() {}
  set name(value) {
    this.first = value;
  }
}
```

Not reported:

{/* good */}

```js
class User {
  get name() {
    return this.first;
  }
  set name(value) {
    this.first = value;
  }
  save() {}
}
```

## Options

```toml bunfig.toml
[lint.rules]
grouped-accessor-pairs = ["error", "getBeforeSet"]
```

| Option                 | What it does                                |
| ---------------------- | ------------------------------------------- |
| `"anyOrder"` (default) | The pair must be adjacent, in either order. |
| `"getBeforeSet"`       | The getter also has to come first.          |
| `"setBeforeGet"`       | The setter also has to come first.          |

| Option              | Default | What it does                                                           |
| ------------------- | ------- | ---------------------------------------------------------------------- |
| `enforceForTSTypes` | `false` | Also check `get` and `set` signatures in interfaces and type literals. |

{/* bad {"options": ["getBeforeSet"]} */}

```js
const volume = {
  set level(value) {
    this.raw = value;
  },
  get level() {
    return this.raw;
  },
};
```

{/* good {"options": ["getBeforeSet"]} */}

```js
const volume = {
  get level() {
    return this.raw;
  },
  set level(value) {
    this.raw = value;
  },
};
```

### `enforceForTSTypes`

{/* good */}

```ts
interface Volume {
  get level(): number;
  mute(): void;
  set level(value: number);
}
```

{/* bad {"options": ["anyOrder", {"enforceForTSTypes": true}]} */}

```ts
interface Volume {
  get level(): number;
  mute(): void;
  set level(value: number);
}
```
