---
title: "logical-assignment-operators"
description: "Require or disallow the logical assignment operators `||=`, `&&=` and `??=`"
---

`options = options || {}` names the variable twice, and it assigns even when `options` keeps its value. `options ||= {}` says the same with one name and assigns only when it has to.

`--fix` rewrites the code when the target is a plain variable. A property can have a getter or a setter, and the rewrite can change how often they run, so `user.name = user.name || "guest"` gets a suggestion instead of a fix.

## Examples

Reported:

{/* bad {"count": 5} */}

```js
options = options || {};
cache = cache ?? new Map();
enabled = enabled && isReady();
title || (title = "Untitled");
user.name = user.name || "guest";
```

Not reported:

{/* good */}

```js
options ||= {};
cache ??= new Map();
enabled &&= isReady();
title ||= "Untitled";
user.name ||= "guest";
```

## Options

```toml bunfig.toml
[lint.rules]
logical-assignment-operators = ["error", "always", { enforceForIfStatements = true }]
```

| Option               | What it does                                              |
| -------------------- | --------------------------------------------------------- |
| `"always"` (default) | Report code that could use a logical assignment operator. |
| `"never"`            | Report every logical assignment operator.                 |

| Option                   | Default | What it does                                                                  |
| ------------------------ | ------- | ----------------------------------------------------------------------------- |
| `enforceForIfStatements` | `false` | With `"always"`, also report an `if` that only assigns to the value it tests. |

{/* bad {"options": ["never"]} */}

```js
options ||= {};
```

{/* good {"options": ["never"]} */}

```js
options = options || {};
```

### `enforceForIfStatements`

{/* good */}

```js
if (!title) {
  title = "Untitled";
}

if (cache == null) cache = new Map();
```

{/* bad {"options": ["always", {"enforceForIfStatements": true}], "count": 2} */}

```js
if (!title) {
  title = "Untitled";
}

if (cache == null) cache = new Map();
```
