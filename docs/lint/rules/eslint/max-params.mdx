---
title: "max-params"
description: "Enforce a maximum number of parameters in function definitions"
---

At a call like `createUser("Ada", "ada@example.com", "admin", "core")` nothing says which argument is which, and swapping two of them goes unnoticed. This rule reports a function that has more parameters than the maximum, which is 3 by default.

## Examples

Reported:

{/* bad */}

```js
function createUser(name, email, role, team) {
  return { name, email, role, team };
}
```

Not reported:

{/* good */}

```js
function createUser({ name, email, role, team }) {
  return { name, email, role, team };
}
```

## Options

```toml bunfig.toml
[lint.rules]
max-params = ["error", 4]
```

| Option          | Default         | What it does                                                                                                                        |
| --------------- | --------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `max`           | `3`             | The number of parameters a function can have. `maximum` is an older name for it.                                                    |
| `countThis`     | `"except-void"` | Whether a TypeScript `this` parameter counts: `"always"`, `"never"`, or `"except-void"`, which counts it unless it is `this: void`. |
| `countVoidThis` | `false`         | An older spelling. `true` is the same as `countThis: "always"`.                                                                     |

A number alone is short for `{ "max": number }`.

By default a typed `this` counts. This function has 3 parameters, so a maximum of 2 reports it:

{/* bad {"options": [2]} */}

```ts
function onClick(this: HTMLButtonElement, event: Event, target: Element) {}
```

With `countThis: "never"` it has 2:

{/* good {"options": [{"max": 2, "countThis": "never"}]} */}

```ts
function onClick(this: HTMLButtonElement, event: Event, target: Element) {}
```

`this: void` does not count by default, so this passes with a maximum of 2:

{/* good {"options": [2]} */}

```ts
function onClick(this: void, event: Event, target: Element) {}
```

With `countThis: "always"` it is reported:

{/* bad {"options": [{"max": 2, "countThis": "always"}]} */}

```ts
function onClick(this: void, event: Event, target: Element) {}
```
