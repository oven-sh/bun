---
title: "max-statements"
description: "Enforce a maximum number of statements in a function"
---

A function with a long list of statements usually does several jobs, and you have to read all of it to change any part. This rule reports a function that has more statements than the maximum, which is 10 by default.

Statements in nested blocks count too. The statements of an inner function count for the inner function only.

## Examples

With a maximum of 3, this function of 4 statements is reported:

{/* bad {"options": [3]} */}

```js
function register(form) {
  const user = parse(form);
  validate(user);
  save(user);
  sendWelcomeMail(user);
}
```

Not reported:

{/* good {"options": [3]} */}

```js
function register(form) {
  const user = parse(form);
  validate(user);
  return saveAndWelcome(user);
}
```

This function has 3 statements, the `if` and the two in its block, so a maximum of 2 reports it:

{/* bad {"options": [2]} */}

```js
function log(message) {
  if (verbose) {
    console.log(message);
    count++;
  }
}
```

## Options

```toml bunfig.toml
[lint.rules]
max-statements = ["error", 15, { ignoreTopLevelFunctions = true }]
```

The first option is the maximum, as a number or as `{ "max": number }`. `maximum` is an older name for `max`. The second option is an object:

| Option                    | Default | What it does                                                                                  |
| ------------------------- | ------- | --------------------------------------------------------------------------------------------- |
| `ignoreTopLevelFunctions` | `false` | Do not report the only top-level function of a file, such as a wrapper around a whole script. |

With it, this passes with a maximum of 2:

{/* good {"options": [2, {"ignoreTopLevelFunctions": true}]} */}

```js
(function () {
  const app = createApp();
  app.use(router);
  app.listen(3000);
})();
```

In a file with two or more top-level functions the option changes nothing:

{/* bad {"options": [2, {"ignoreTopLevelFunctions": true}]} */}

```js
function start() {
  const app = createApp();
  app.use(router);
  app.listen(3000);
}

function stop() {}
```
