---
title: "no-func-assign"
description: "Disallow assigning to the name of a function declaration"
---

Assigning to the name of a `function` declaration replaces the function for every caller from then on. It is almost always a mistake: a typo, or a variable that happens to have the same name as a function in the file.

The name of a function expression, such as `retry` in `const run = function retry() {}`, is checked too.

This rule is on by default in JavaScript files. In TypeScript files it is off by default, because TypeScript reports the same mistake.

## Examples

Reported:

{/* bad */}

```js
function format(value) {
  return String(value);
}

format = value => value.toFixed(2);
```

{/* bad */}

```js
const run = function retry() {
  retry = null;
};
```

Not reported:

{/* good */}

```js
let format = function (value) {
  return String(value);
};

format = value => value.toFixed(2);
```

A parameter or a local variable with the same name is a different variable:

{/* good */}

```js
function total(items) {
  let total = 0;
  for (const item of items) {
    total += item.price;
  }
  return total;
}
```
