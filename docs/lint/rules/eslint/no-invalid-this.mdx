---
title: "no-invalid-this"
description: "Disallow `this` where its value is `undefined`"
---

In strict mode, `this` is `undefined` at the top level of a module and in a plain function that is called without an object. Reading a property from it throws a `TypeError`. The usual cause is a callback written with `function` inside a method: it does not get the method's `this`.

`this` is fine in methods, constructors, class fields, and arrow functions inside any of them. It is also fine in a function that is given its `this`:

- with `.bind()`, `.call()` or `.apply()`
- with the last argument of `forEach()` and similar methods
- by being assigned to a property

If `this` comes from somewhere the rule cannot see, say so with a `@this` tag in the function's doc comment or, in TypeScript, a `this` parameter.

Code outside strict mode is not reported. There `this` falls back to the global object.

## Examples

Reported:

{/* bad {"count": 3} */}

```js
export const root = this;

function describe() {
  return this.name;
}

class Cart {
  total = 0;

  add(items) {
    items.forEach(function (item) {
      this.total += item.price;
    });
  }
}
```

Not reported:

{/* good */}

```js
const user = {
  name: "Ada",
  describe() {
    return this.name;
  },
};

class Cart {
  total = 0;

  add(items) {
    items.forEach(item => {
      this.total += item.price;
    });
  }

  remove(items) {
    items.forEach(function (item) {
      this.total -= item.price;
    }, this);
  }
}
```

{/* good */}

```js
const redraw = function () {
  this.clear();
}.bind(chart);

chart.reset = function () {
  this.points = [];
};

/** @this {HTMLButtonElement} */
function onClick() {
  this.disabled = true;
}
```

{/* good */}

```ts
function onClick(this: HTMLButtonElement) {
  this.disabled = true;
}
```

Not reported in a CommonJS file without `"use strict"`:

{/* good {"filename": "user.cjs"} */}

```js
function describe() {
  return this.name;
}
```

## Options

| Option             | Default | What it does                                                                       |
| ------------------ | ------- | ---------------------------------------------------------------------------------- |
| `capIsConstructor` | `true`  | Treat a function with a capitalized name as a constructor, and allow `this` in it. |

{/* good */}

```js
function User(name) {
  this.name = name;
}
```

{/* bad {"options": [{"capIsConstructor": false}]} */}

```js
function User(name) {
  this.name = name;
}
```
