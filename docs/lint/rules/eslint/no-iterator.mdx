---
title: "no-iterator"
description: "Disallow the `__iterator__` property"
---

No current engine looks at a property called `__iterator__`. An object that defines it is not iterable, and `for (const song of playlist)` throws a `TypeError`. The method that `for...of`, spread and destructuring call is `[Symbol.iterator]`.

## Examples

Reported:

{/* bad {"count": 2} */}

```js
Playlist.prototype.__iterator__ = function () {
  return new SongIterator(this);
};

const iterate = playlist["__iterator__"];
```

Not reported:

{/* good */}

```js
Playlist.prototype[Symbol.iterator] = function* () {
  yield* this.songs;
};

const iterate = playlist[Symbol.iterator];
```
