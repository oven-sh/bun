---
title: "no-new-func"
description: "Disallow creating functions from strings with `Function`"
---

`Function` compiles a string into code at run time, like `eval`. If any part of the string comes from a user, they can run what they like. The code in the string is also invisible to the linter, the type checker and the bundler, and a Content Security Policy without `unsafe-eval` blocks it.

The rule reports `new Function(..)`, `Function(..)`, `Function.call(..)`, `Function.apply(..)` and `Function.bind(..)`.

## Examples

Reported:

{/* bad */}

```js
const add = new Function("a", "b", "return a + b");
```

{/* bad */}

```js
const run = Function.apply(null, ["input", userCode]);
```

Not reported:

{/* good */}

```js
const add = (a, b) => a + b;

if (callback instanceof Function) {
  callback();
}
```
