---
title: "no-new-symbol"
description: "Disallow `new Symbol()`"
---

`Symbol` starts with a capital letter but is not a constructor. `new Symbol("id")` throws a `TypeError` when it runs. Call it without `new`.

ESLint has deprecated this rule. Use `no-new-native-nonconstructor` instead, which also covers `BigInt`.

## Examples

Reported:

{/* bad */}

```js
const id = new Symbol("id");
```

Not reported:

{/* good */}

```js
const id = Symbol("id");
```
