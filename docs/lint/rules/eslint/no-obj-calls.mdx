---
title: "no-obj-calls"
description: "Disallow calling `Math`, `JSON`, `Reflect`, `Atomics`, `Intl` and `Temporal` as functions"
---

These globals start with a capital letter, but they are plain objects that hold functions. `Math()` and `new JSON()` throw a `TypeError` when they run.

The rule follows the object through variables and through `globalThis`.

This rule is on by default in JavaScript files.

## Examples

Reported:

{/* bad */}

```js
const random = Math();
```

{/* bad */}

```js
const parser = new JSON();
```

{/* bad {"count": 2} */}

```js
const format = Intl;
const text = format("en-US");

const now = globalThis.Reflect();
```

Not reported:

{/* good */}

```js
const random = Math.random();
const data = JSON.parse(body);
const text = new Intl.NumberFormat("en-US").format(total);
```
