---
title: "no-path-concat"
description: "Disallow building paths with `+` from `__dirname` or `__filename`"
---

A path built with `+` has the separator written into the string. `__dirname + "/config.json"` mixes `\` and `/` on Windows, and a forgotten slash gives a wrong path without an error. `path.join()` and `path.resolve()` put in the right separator and clean up `..` and doubled slashes.

## Examples

Reported:

{/* bad */}

```js
const configPath = __dirname + "/config.json";
```

Not reported:

{/* good */}

```js
const path = require("node:path");

const configPath = path.join(__dirname, "config.json");
```

Only `+` is checked. A template literal has the same problem, but it is not reported:

{/* good */}

```js
const configPath = `${__dirname}/config.json`;
```
