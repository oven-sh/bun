---
title: "no-prototype-builtins"
description: "Disallow calling `hasOwnProperty` and other `Object.prototype` methods on the object itself"
---

`data.hasOwnProperty("id")` only works if `data` inherits the method and has no property of its own with that name. An object made with `Object.create(null)` does not inherit it, so the call throws. An object parsed from JSON can have its own `hasOwnProperty` key, so whoever sends the input can make the call throw too.

The rule reports calls to `hasOwnProperty`, `isPrototypeOf` and `propertyIsEnumerable`. Use `Object.hasOwn()`, or call the method from `Object.prototype`.

This rule is on by default.

## Examples

Reported:

{/* bad {"count": 2} */}

```js
const data = JSON.parse(body);

if (data.hasOwnProperty("id")) {
  update(data.id);
}

const isChild = base.isPrototypeOf(data);
```

Not reported:

{/* good */}

```js
const data = JSON.parse(body);

if (Object.hasOwn(data, "id")) {
  update(data.id);
}

const isChild = Object.prototype.isPrototypeOf.call(base, data);
```
