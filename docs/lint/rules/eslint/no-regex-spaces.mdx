---
title: "no-regex-spaces"
description: "Disallow several spaces in a row in a regular expression"
---

In `/error   code/` you cannot tell at a glance whether there are two, three or four spaces. ` {3}` says it.

The rule looks at regular expression literals and at a string passed to `RegExp`. Spaces inside a character class such as `[  ]` are not reported.

`--fix` replaces the spaces with one space and a count.

This rule is on by default.

## Examples

Reported:

{/* bad {"count": 2} */}

```js
const line = /error   code/;
const header = new RegExp("name  value");
```

Not reported:

{/* good */}

```js
const line = /error {3}code/;
const header = new RegExp("name {2}value");
const anyGap = /name +value/;
```
