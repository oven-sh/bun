---
title: "no-ternary"
description: "Disallow the `? :` operator"
---

`test ? a : b` puts a branch in the middle of an expression. Some teams find an `if` and `else` easier to read, to step through in a debugger and to extend later, and ban the operator everywhere. This rule reports every use of it.

## Examples

Reported:

{/* bad */}

```js
const label = count === 1 ? "item" : "items";
```

Not reported:

{/* good */}

```js
let label = "items";
if (count === 1) {
  label = "item";
}
```

## When not to use it

A short ternary is often the clearest way to choose between two values, and it lets the variable stay `const`. If only the nested ones bother you, use `no-nested-ternary`.
