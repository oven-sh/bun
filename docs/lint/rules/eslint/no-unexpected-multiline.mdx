---
title: "no-unexpected-multiline"
description: "Disallow lines that look like a new statement but continue the previous one"
---

JavaScript only ends a statement at a line break if the next line cannot continue it. A line that starts with `(`, `[`, a template literal, or `/` can. Two lines that look like two statements then run as one call, property access, tagged template, or division.

This mostly happens in code without semicolons.

This rule is on by default.

## Examples

Reported. This reads an element of what `getName()` returns:

{/* bad */}

```js
const name = getName()[(first, last)].forEach(print);
```

This calls `now` with a function as its argument:

{/* bad */}

```js
const started = now(async () => {
  await run();
})();
```

This calls `prefix` as a template tag:

{/* bad */}

```js
const label = prefix`item-${id}`.trim();
```

This divides `input` by `id` and then by `g.test(text)`:

{/* bad */}

```js
const value = input / id / g.test(text);
```

Not reported:

{/* good */}

```js
const name = getName();
[first, last].forEach(print);

const started = now;
(async () => {
  await run();
})();
```

If you do mean one expression, keep the opening `(` or `[` on the first line:

{/* good */}

```js
const name = getName(user);
```
