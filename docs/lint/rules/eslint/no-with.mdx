---
title: "no-with"
description: "Disallow `with` statements"
---

Inside `with (object)`, a name such as `x` means `object.x` if the object has that property, and the variable `x` otherwise. You cannot tell which one by reading the code, and adding a property to the object changes what the block does.

`with` is already a syntax error in strict mode, which includes every ES module and every class. The rule matters for CommonJS files and old scripts.

This rule is on by default in JavaScript files.

## Examples

Reported, in a CommonJS file:

{/* bad {"filename": "legacy.cjs"} */}

```js
with (point) {
  distance = Math.sqrt(x * x + y * y);
}
```

Not reported:

{/* good {"filename": "legacy.cjs"} */}

```js
const { x, y } = point;
distance = Math.sqrt(x * x + y * y);
```
