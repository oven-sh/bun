---
title: "symbol-description"
description: "Require a description when creating a `Symbol`"
---

A symbol made with `Symbol()` prints as `Symbol()` in logs and in the debugger, so you cannot tell one from another. With a description it prints as `Symbol(userId)`, and `symbol.description` returns the text.

Any argument counts as a description, not only a string literal. A function of your own named `Symbol` is not checked.

## Examples

Reported:

{/* bad */}

```js
const userId = Symbol();
```

Not reported:

{/* good */}

```js
const userId = Symbol("userId");

function makeKey(name) {
  return Symbol(name);
}
```
