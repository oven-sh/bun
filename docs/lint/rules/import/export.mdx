---
title: "import/export"
description: "Disallow exporting the same name twice, and `export *` from a file with no named exports"
---

A module can export each name once. The case that is easy to miss is `export *`. If two files both export `format` and you re-export both with `export *`, JavaScript drops the name without a word, and `import { format }` fails somewhere else. If your own file exports `format` too, yours wins and the other one is hidden.

The rule reads the files behind each `export *`. It also reports an `export *` from a file that has no named exports, because that line re-exports nothing: `export *` never passes on a default export.

In TypeScript, function overloads are allowed, and so are a type and a value with the same name, and a namespace merged with a function, class or enum.

## Examples

Reported:

{/* file "dates.js" */}

```js
export function format(date) {
  return date.toISOString();
}
```

{/* bad */}

```js
export * from "./dates.js";

export function format(value) {
  return String(value);
}
```

{/* file "logger.js" */}

```js
export default function log(message) {
  console.log(message);
}
```

{/* bad */}

```js
export * from "./logger.js";
```

{/* bad */}

```ts
function print(value: unknown) {
  console.log(value);
}

export function format(value: unknown) {
  return String(value);
}

export { print as format };
```

Not reported:

{/* file "dates.js" */}

```js
export function format(date) {
  return date.toISOString();
}
```

{/* good */}

```js
export { format as formatDate } from "./dates.js";

export function format(value) {
  return String(value);
}
```

{/* file "logger.js" */}

```js
export default function log(message) {
  console.log(message);
}
```

{/* good */}

```js
export { default as log } from "./logger.js";
```

{/* good */}

```ts
export function parse(input: string): number;
export function parse(input: number): number;
export function parse(input: string | number): number {
  return Number(input);
}

export namespace parse {
  export const radix = 10;
}

export type Level = "info" | "error";
export const Level = { info: "info", error: "error" } as const;
```
