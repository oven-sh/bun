---
title: "import/extensions"
description: "Enforce that import paths always include the file extension, or never do"
---

`import "./user"` and `import "./user.js"` can name the same file. Browsers and Node.js only accept the second in ES modules, while bundlers and Bun accept both. This rule keeps a project on one style, for all files or for each extension.

It checks `import`, `export ... from`, `import()` and `require()`. Built-in modules and bare package names such as `"react"` or `"@babel/core"` are never checked.

## Examples

Reported:

{/* file "user.js" */}

```js
export function createUser(name) {
  return { name };
}
```

{/* bad {"options": ["always"]} */}

```js
import { createUser } from "./user";
```

Not reported:

{/* file "user.js" */}

```js
export function createUser(name) {
  return { name };
}
```

{/* good {"options": ["always"]} */}

```js
import { createUser } from "./user.js";
import { join } from "node:path";
```

## Options

```toml bunfig.toml
[lint.rules]
"import/extensions" = ["error", "ignorePackages", { ts = "never", tsx = "never" }]
```

The first option sets the style for every extension:

| Option              | What it does                                                                    |
| ------------------- | ------------------------------------------------------------------------------- |
| `"never"` (default) | Report an extension, if the path finds the same file without it.                |
| `"always"`          | Report a path without an extension.                                             |
| `"ignorePackages"`  | Like `"always"`, but paths into packages such as `"lodash/fp"` are not checked. |

{/* file "user.js" */}

```js
export function createUser(name) {
  return { name };
}
```

{/* bad {"options": ["never"]} */}

```js
import { createUser } from "./user.js";
```

{/* bad {"options": ["always"]} */}

```js
import map from "lodash/fp/map";
```

{/* good {"options": ["ignorePackages"]} */}

```js
import map from "lodash/fp/map";
import { useState } from "react";
```

An object after it, or in its place, has exceptions and more settings:

| Option                               | Default          | What it does                                                                                                                                                                                                                          |
| ------------------------------------ | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| an extension, such as `js` or `json` | the first option | `"always"` or `"never"` for files with that extension.                                                                                                                                                                                |
| `pattern`                            | `{}`             | The same list of extensions, as an object of its own. Put the extensions here when you also set one of the options below.                                                                                                             |
| `ignorePackages`                     | `false`          | Do not require an extension in paths into packages.                                                                                                                                                                                   |
| `checkTypeImports`                   | `false`          | Also require extensions in `import type` and `export type`.                                                                                                                                                                           |
| `pathGroupOverrides`                 | `[]`             | A list of `{ pattern, action }`. Paths that match the glob `pattern` are skipped with `"ignore"`, and checked even if they look like a package with `"enforce"`. Only read next to `pattern`, `ignorePackages` or `checkTypeImports`. |

{/* good {"options": ["never", {"json": "always"}]} */}

```js
import { createUser } from "./user";
import settings from "./settings.json";
```

{/* good {"options": ["always"]} */}

```ts
import type { User } from "./user";
```

{/* bad {"options": ["always", {"checkTypeImports": true}]} */}

```ts
import type { User } from "./user";
```

{/* bad {"options": ["ignorePackages"]} */}

```js
import { routes } from "~/generated/routes";
```

{/* good {"options": ["always", {"ignorePackages": true, "pathGroupOverrides": [{"pattern": "~/generated/**", "action": "ignore"}]}]} */}

```js
import { routes } from "~/generated/routes";
```
