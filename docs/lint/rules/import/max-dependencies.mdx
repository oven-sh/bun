---
title: "import/max-dependencies"
description: "Enforce a maximum number of modules that a file can import"
---

A file that imports from many modules usually does too many things, and a change in any of those modules can break it. This rule reports a file that depends on more than `max` modules, 10 by default.

Each module counts once, however many names or statements import from it. `import`, `export ... from`, `import()` and `require()` all count.

## Examples

Reported:

{/* bad {"options": [{"max": 2}]} */}

```js
import { readFile } from "node:fs/promises";
import { join } from "node:path";
import { parse } from "./parser.js";
```

Not reported:

{/* good {"options": [{"max": 2}]} */}

```js
import { readFile } from "node:fs/promises";
import { writeFile } from "node:fs/promises";
import { join, resolve } from "node:path";
```

## Options

| Option              | Default | What it does                                |
| ------------------- | ------- | ------------------------------------------- |
| `max`               | `10`    | The number of modules a file can depend on. |
| `ignoreTypeImports` | `false` | Do not count `import type` statements.      |

If you pass an options object, give it a `max`. The default of 10 only applies when there are no options at all.

{/* bad {"options": [{"max": 1}]} */}

```ts
import { parse } from "./parser";
import type { Token } from "./tokens";
```

{/* good {"options": [{"max": 1, "ignoreTypeImports": true}]} */}

```ts
import { parse } from "./parser";
import type { Token } from "./tokens";
```
