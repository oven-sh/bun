---
title: "import/no-extraneous-dependencies"
description: "Disallow importing a package that `package.json` does not list"
---

A package can be in `node_modules` only because another package depends on it. Importing it works on your machine until that other package drops or upgrades it, and it fails for whoever installs your package, because nothing tells the package manager to install it.

The rule reads the closest `package.json` above the file. A package is fine if it is in `dependencies`, `devDependencies`, `optionalDependencies`, `peerDependencies` or `bundledDependencies`. `import`, `export ... from`, `import()` and `require()` are checked. Relative paths, Node.js builtins, `import type` and packages that are not installed are not.

## Examples

Here `ms` is installed, but only `express` is listed. Reported:

{/* file "package.json" */}

```json package.json
{
  "name": "shop",
  "dependencies": { "express": "^5.0.0" }
}
```

{/* file "node_modules/ms/package.json" */}

```json node_modules/ms/package.json
{ "name": "ms", "main": "index.js" }
```

{/* file "node_modules/ms/index.js" */}

```js node_modules/ms/index.js
module.exports = text => Number.parseInt(text) * 1000;
```

{/* bad {"count": 1} */}

```js
import express from "express";
import ms from "ms";
```

Not reported, with the same `package.json`:

{/* file "package.json" */}

```json package.json
{
  "name": "shop",
  "dependencies": { "express": "^5.0.0" }
}
```

{/* good */}

```js
import express from "express";
import { join } from "node:path";
import { cart } from "./cart";
```

## Options

| Option                 | Default | What it does                                                                                                                                                                      |
| ---------------------- | ------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `devDependencies`      | `true`  | `false` reports an import of a package that is only in `devDependencies`. An array of globs names the files that may import them.                                                 |
| `optionalDependencies` | `true`  | The same for `optionalDependencies`.                                                                                                                                              |
| `peerDependencies`     | `true`  | The same for `peerDependencies`.                                                                                                                                                  |
| `bundledDependencies`  | `true`  | The same for `bundledDependencies`.                                                                                                                                               |
| `packageDir`           | none    | A directory, or an array of directories, to read `package.json` from instead of the closest one, relative to where `bun lint` runs. In a monorepo, name the package and the root. |
| `includeInternal`      | `false` | Also check names that resolve to a file in your own project.                                                                                                                      |
| `includeTypes`         | `false` | Also check `import type`.                                                                                                                                                         |

Most projects allow `devDependencies` in tests and scripts only:

```toml bunfig.toml
[lint.rules]
"import/no-extraneous-dependencies" = ["error", { devDependencies = ["**/*.test.js", "scripts/**"] }]
```

With that, code that ships cannot import a package that is missing in production:

{/* file "package.json" */}

```json package.json
{
  "name": "shop",
  "devDependencies": { "ms": "^2.0.0" }
}
```

{/* file "node_modules/ms/package.json" */}

```json node_modules/ms/package.json
{ "name": "ms", "main": "index.js" }
```

{/* file "node_modules/ms/index.js" */}

```js node_modules/ms/index.js
module.exports = text => Number.parseInt(text) * 1000;
```

{/* bad {"filename": "cart.js", "options": [{"devDependencies": ["{**,.}/*.test.js", "scripts/**"]}]} */}

```js cart.js
import ms from "ms";
```

A test can:

{/* file "package.json" */}

```json package.json
{
  "name": "shop",
  "devDependencies": { "ms": "^2.0.0" }
}
```

{/* file "node_modules/ms/package.json" */}

```json node_modules/ms/package.json
{ "name": "ms", "main": "index.js" }
```

{/* file "node_modules/ms/index.js" */}

```js node_modules/ms/index.js
module.exports = text => Number.parseInt(text) * 1000;
```

{/* good {"filename": "cart.test.js", "options": [{"devDependencies": ["{**,.}/*.test.js", "scripts/**"]}]} */}

```js cart.test.js
import ms from "ms";
```
