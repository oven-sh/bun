---
title: "import/no-mutable-exports"
description: "Disallow exporting a variable declared with `let` or `var`"
---

An import is a live view of the exported variable. If the module assigns to an exported `let`, the value changes in every file that imported it, and nothing at the import says so. Code that read the value once keeps the old one, code that reads it again gets the new one.

It makes no difference whether the variable is exported where it is declared or later with `export { count }` or `export default count`.

## Examples

Reported:

{/* bad */}

```js
export let count = 0;

export function increment() {
  count += 1;
}
```

{/* bad */}

```js
let count = 0;

export { count };
```

Not reported:

{/* good */}

```js
let count = 0;

export const getCount = () => count;

export function increment() {
  count += 1;
}
```
