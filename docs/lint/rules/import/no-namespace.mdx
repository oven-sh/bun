---
title: "import/no-namespace"
description: "Disallow `import * as name` in favor of named imports"
---

`import * as utils` does not say which exports a file uses. You have to search for every `utils.` to find out, and a typo such as `utils.clmap` is only `undefined` at runtime, while a named import of a name that does not exist is an error when the module loads.

`--fix` turns the namespace into named imports if it is only used as `utils.name`. If the namespace object itself is passed around, or is not used at all, nothing is changed.

## Examples

Reported:

{/* bad */}

```js
import * as utils from "./utils";

const width = utils.clamp(utils.sum(sizes), 0, 100);
```

Not reported:

{/* good */}

```js
import { clamp, sum } from "./utils";

const width = clamp(sum(sizes), 0, 100);
```

## Options

| Option   | Default | What it does                                                                                                                 |
| -------- | ------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `ignore` | `[]`    | Globs for import paths that may be imported as a namespace. A glob without a `/` is compared with the last part of the path. |

{/* good {"options": [{"ignore": ["*.css"]}]} */}

```js
import * as styles from "./components/button.module.css";
```

{/* bad {"options": [{"ignore": ["*.css"]}]} */}

```js
import * as utils from "./utils";
```
