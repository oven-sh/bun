---
title: "import/no-restricted-paths"
description: "Disallow files in one folder from importing files in another"
---

Some folders must not depend on others: code that ships to the browser must not pull in server code, and a shared library must not import from the app that uses it. This rule lets you write those borders down as zones.

The rule does nothing until you give it zones. It checks `import`, `export .. from`, `import()` and `require()`, and only paths that resolve to a file.

## Examples

```toml bunfig.toml
[lint.rules]
"import/no-restricted-paths" = ["error", { zones = [{ target = "./src/client", from = "./src/server" }] }]
```

With this zone, files in `src/client` cannot import files in `src/server`.

Reported:

{/* file "src/server/db.js" */}

```js src/server/db.js
export function query() {}
```

{/* bad {"filename": "src/client/app.js", "options": [{"zones": [{"target": "{**,}/src/client/**", "from": "{**,}/src/server/**"}]}]} */}

```js src/client/app.js
import { query } from "../server/db.js";
```

Not reported:

{/* file "src/shared/format.js" */}

```js src/shared/format.js
export function formatDate() {}
```

{/* good {"filename": "src/client/app.js", "options": [{"zones": [{"target": "{**,}/src/client/**", "from": "{**,}/src/server/**"}]}]} */}

```js src/client/app.js
import { formatDate } from "../shared/format.js";
```

The other direction is not restricted:

{/* file "src/client/app.js" */}

```js src/client/app.js
export function App() {}
```

{/* good {"filename": "src/server/render.js", "options": [{"zones": [{"target": "{**,}/src/client/**", "from": "{**,}/src/server/**"}]}]} */}

```js src/server/render.js
import { App } from "../client/app.js";
```

## Options

| Option     | Default                             | What it does                                            |
| ---------- | ----------------------------------- | ------------------------------------------------------- |
| `zones`    | `[]`                                | The list of zones.                                      |
| `basePath` | the directory you run `bun lint` in | The directory that `target` and `from` are relative to. |

Each zone has these keys:

| Key       | What it does                                                                                                         |
| --------- | -------------------------------------------------------------------------------------------------------------------- |
| `target`  | The files the restriction applies to. A path, a glob, or a list of them. A path to a folder covers everything in it. |
| `from`    | The files that `target` cannot import. A path, a glob, or a list. A list is either all paths or all globs.           |
| `except`  | Files inside `from` that can be imported after all.                                                                  |
| `message` | Text to add to the report.                                                                                           |

If `from` is a path, each `except` is a path relative to `from` and must be inside it. If `from` is a glob, each `except` must be a glob too.

With this zone, `src/client/app.js` can import `../server/types.js` and nothing else from `src/server`:

```toml bunfig.toml
[lint.rules]
"import/no-restricted-paths" = ["error", { zones = [{ target = "./src/client", from = "./src/server", except = ["./types.js"], message = "Call the API instead." }] }]
```
