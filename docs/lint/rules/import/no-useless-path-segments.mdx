---
title: "import/no-useless-path-segments"
description: "Disallow path segments in imports that can be removed"
---

`./../format.js` works, and so does `../pages/header.js` written inside `pages`, but each has a shorter spelling that points to the same file. The long ones are usually left over from moving a file, and they make one module look like two when you search for it.

Only relative paths are checked. `--fix` writes the shorter path.

## Examples

Reported:

{/* file "src/format.js" */}

```js src/format.js
export function formatDate() {}
```

{/* file "src/pages/header.js" */}

```js src/pages/header.js
export function Header() {}
```

{/* bad {"filename": "src/pages/home.js", "count": 2} */}

```js src/pages/home.js
import { formatDate } from "./../format.js";
import { Header } from "../pages/header.js";
```

Not reported:

{/* file "src/format.js" */}

```js src/format.js
export function formatDate() {}
```

{/* file "src/pages/header.js" */}

```js src/pages/header.js
export function Header() {}
```

{/* good {"filename": "src/pages/home.js"} */}

```js src/pages/home.js
import { formatDate } from "../format.js";
import { Header } from "./header.js";
```

## Options

| Option           | Default | What it does                                                                                                  |
| ---------------- | ------- | ------------------------------------------------------------------------------------------------------------- |
| `commonjs`       | `false` | Also check `require()`.                                                                                       |
| `noUselessIndex` | `false` | Also report a path that ends in `/index` or `/index.js`, because the folder's name resolves to the same file. |

With `commonjs`:

{/* bad {"options": [{"commonjs": true}]} */}

```js
const settings = require("./config/../settings.js");
```

With `noUselessIndex`, this is reported:

{/* file "parts/index.js" */}

```js parts/index.js
export function Footer() {}
```

{/* bad {"options": [{"noUselessIndex": true}]} */}

```js
import { Footer } from "./parts/index.js";
```

And this is not:

{/* file "parts/index.js" */}

```js parts/index.js
export function Footer() {}
```

{/* good {"options": [{"noUselessIndex": true}]} */}

```js
import { Footer } from "./parts";
```

## When not to use it

Leave `noUselessIndex` off for code that runs as ES modules in Node.js or in a browser. There an import has to name the file, and `./parts` does not find `./parts/index.js`.
