---
title: "jest/expect-expect"
description: "Require every test to make at least one assertion"
---

A test with no assertion passes as long as the code does not throw. It is green in the report whether the result is right or wrong. Most of the time the `expect` was forgotten, or removed while the test was being changed.

`test.todo` is not checked. `test.skip` is.

## Examples

Reported:

{/* bad {"count": 2} */}

```ts
import { test } from "@jest/globals";

test("parses the port", () => {
  parseConfig("port = 3000");
});

test.skip("parses the host", () => {
  parseConfig("host = localhost");
});
```

Not reported:

{/* good */}

```ts
import { expect, test } from "@jest/globals";

test("parses the port", () => {
  expect(parseConfig("port = 3000")).toEqual({ port: 3000 });
});

test.todo("parses the host");
```

## Options

| Option                         | Default      | What it does                                                                                        |
| ------------------------------ | ------------ | --------------------------------------------------------------------------------------------------- |
| `assertFunctionNames`          | `["expect"]` | The functions that count as an assertion. Your list replaces the default, so keep `"expect"` in it. |
| `additionalTestBlockFunctions` | `[]`         | Other Jest functions to check like `test`, such as `"afterEach"`.                                   |

### `assertFunctionNames`

The rule does not look inside the helpers that a test calls. This test is reported even though `checkUser` calls `expect`:

{/* bad */}

```ts
import { expect, test } from "@jest/globals";

function checkUser(user) {
  expect(user.id).toBeGreaterThan(0);
}

test("creates a user", () => {
  checkUser(createUser());
});
```

Add the helper's name:

```toml bunfig.toml
[lint.rules]
"jest/expect-expect" = ["error", { assertFunctionNames = ["expect", "checkUser"] }]
```

{/* good {"options": [{"assertFunctionNames": ["expect", "checkUser"]}]} */}

```ts
import { expect, test } from "@jest/globals";

function checkUser(user) {
  expect(user.id).toBeGreaterThan(0);
}

test("creates a user", () => {
  checkUser(createUser());
});
```

A name can be a chain with dots. `*` stands for any letters and digits in one part of the chain, and `**` for any number of parts. Upper and lower case are treated the same.

{/* good {"options": [{"assertFunctionNames": ["expect", "request.**.expect"]}]} */}

```ts
import { test } from "@jest/globals";

test("is healthy", async () => {
  await request(app).get("/health").expect(200);
});
```

### `additionalTestBlockFunctions`

This option only works for functions that come from Jest. A wrapper of your own is not checked, even if you list it.

{/* bad {"options": [{"additionalTestBlockFunctions": ["afterEach"]}]} */}

```ts
import { afterEach } from "@jest/globals";

afterEach(() => {
  closeDatabase();
});
```

{/* good {"options": [{"additionalTestBlockFunctions": ["testWithDatabase"]}]} */}

```ts
import { afterAll } from "@jest/globals";
import { closeDatabase, testWithDatabase } from "./helpers";

afterAll(closeDatabase);

testWithDatabase("saves the user", db => {
  db.save(createUser());
});
```
