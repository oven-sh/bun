---
title: "jest/no-identical-title"
description: "Disallow two tests or two `describe` blocks with the same title in one block"
---

When two tests in the same block share a title, a failure report does not tell you which one failed, and filtering by name runs both. The second one is often a copy that kept the old title.

Titles are compared inside one block. The same title in two different `describe` blocks is fine.

## Examples

Reported:

{/* bad */}

```ts
import { describe, expect, test } from "@jest/globals";

describe("parsePrice", () => {
  test("reads a number", () => {
    expect(parsePrice("12")).toBe(12);
  });

  test("reads a number", () => {
    expect(parsePrice("12.50")).toBe(12.5);
  });
});
```

Two `describe` blocks next to each other are compared the same way:

{/* bad */}

```ts
import { describe, test } from "@jest/globals";

describe("cart", () => {
  test("adds an item", () => {});
});

describe("cart", () => {
  test("removes an item", () => {});
});
```

Not reported:

{/* good */}

```ts
import { describe, expect, test } from "@jest/globals";

describe("parsePrice", () => {
  test("reads a whole number", () => {
    expect(parsePrice("12")).toBe(12);
  });

  test("reads a decimal", () => {
    expect(parsePrice("12.50")).toBe(12.5);
  });
});

describe("formatPrice", () => {
  test("reads a whole number", () => {
    expect(formatPrice(12)).toBe("12.00");
  });
});
```

Only titles that are plain strings are compared. A title built from a variable is skipped, and so is `.each`, which fills in the title for each row:

{/* good */}

```ts
import { expect, test } from "@jest/globals";

test.each([1, 2])("doubles %i", n => {
  expect(double(n)).toBe(n * 2);
});

test.each([-1, -2])("doubles %i", n => {
  expect(double(n)).toBe(n * 2);
});

test("rounds " + mode, () => {});
test("rounds " + mode, () => {});
```
