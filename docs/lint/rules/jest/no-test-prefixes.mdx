---
title: "jest/no-test-prefixes"
description: "Require `.only` and `.skip` instead of the `f` and `x` prefixes"
---

`fit` and `fdescribe` are short names for `it.only` and `describe.only`. `xit`, `xtest` and `xdescribe` are short names for `it.skip`, `test.skip` and `describe.skip`. One extra letter is easy to miss in a review, and a search for `.only` or `.skip` does not find it.

`--fix` rewrites the short name to the long one.

## Examples

Reported:

{/* bad {"count": 3} */}

```ts
import { expect, fit, xdescribe, xtest } from "@jest/globals";

fit("adds", () => {
  expect(1 + 1).toBe(2);
});

xtest("subtracts", () => {
  expect(3 - 1).toBe(2);
});

xdescribe("division", () => {});
```

Not reported:

{/* good */}

```ts
import { describe, expect, it, test } from "@jest/globals";

it.only("adds", () => {
  expect(1 + 1).toBe(2);
});

test.skip("subtracts", () => {
  expect(3 - 1).toBe(2);
});

describe.skip("division", () => {});
```

What follows the name is kept. This is reported, and `--fix` turns it into `it.skip.each`:

{/* bad */}

```ts
import { expect, xit } from "@jest/globals";

xit.each([1, 2, 3])("%i is positive", n => {
  expect(n).toBeGreaterThan(0);
});
```
