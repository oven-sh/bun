---
title: "jest/prefer-jest-mocked"
description: "Require `jest.mocked(fn)` instead of `fn as jest.Mock`"
---

`fetchUser as jest.Mock` replaces the type of the function with a mock of anything, so `mockReturnValue` accepts a value that the real function can never return. `jest.mocked(fetchUser)` keeps the parameters and the return type, and a mock value of the wrong shape is a type error.

The rule reports a cast to `jest.Mock`, `jest.MockedFunction`, `jest.MockedClass` or `jest.MockedObject`, with or without type arguments.

`--fix` rewrites the cast to `jest.mocked()`.

## Examples

Reported:

{/* bad */}

```ts
import { jest } from "@jest/globals";
import { fetchUser } from "./api";

jest.mock("./api");

(fetchUser as jest.Mock).mockReturnValue({ name: "Ada" });
```

{/* bad */}

```ts
import { jest } from "@jest/globals";
import { fetchUser } from "./api";

const mockFetchUser = fetchUser as jest.MockedFunction<typeof fetchUser>;
```

Not reported:

{/* good */}

```ts
import { jest } from "@jest/globals";
import { fetchUser } from "./api";

jest.mock("./api");

jest.mocked(fetchUser).mockReturnValue({ name: "Ada" });
```
