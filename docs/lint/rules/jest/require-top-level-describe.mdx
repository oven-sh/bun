---
title: "jest/require-top-level-describe"
description: "Require tests and hooks to be inside a `describe` block"
---

A test at the top level of a file shows up in the output with no group name, so a failure says "starts empty" but not what starts empty. A hook at the top level runs for every test in the file, including the ones somebody adds later for something else. Inside a `describe`, both say what they belong to.

## Examples

Reported:

{/* bad {"count": 2} */}

```js
import { beforeEach, expect, test } from "@jest/globals";

beforeEach(() => {
  cart.clear();
});

test("starts empty", () => {
  expect(cart.size).toBe(0);
});
```

Not reported:

{/* good */}

```js
import { beforeEach, describe, expect, test } from "@jest/globals";

describe("cart", () => {
  beforeEach(() => {
    cart.clear();
  });

  test("starts empty", () => {
    expect(cart.size).toBe(0);
  });
});
```

## Options

| Option                         | Default  | What it does                                                                                                              |
| ------------------------------ | -------- | ------------------------------------------------------------------------------------------------------------------------- |
| `maxNumberOfTopLevelDescribes` | no limit | How many `describe` blocks a file can have at the top level. Each one after that is reported. Nested blocks do not count. |

{/* bad {"options": [{"maxNumberOfTopLevelDescribes": 1}], "count": 1} */}

```js
import { describe, test } from "@jest/globals";

describe("cart", () => {
  test.todo("starts empty");
});

describe("checkout", () => {
  test.todo("charges the card");
});
```

{/* good {"options": [{"maxNumberOfTopLevelDescribes": 1}]} */}

```js
import { describe, test } from "@jest/globals";

describe("shop", () => {
  describe("cart", () => {
    test.todo("starts empty");
  });

  describe("checkout", () => {
    test.todo("charges the card");
  });
});
```
