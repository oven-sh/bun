---
title: "jsx-a11y/anchor-has-content"
description: "Require links to have content that a screen reader can read"
---

A link with nothing in it, or with only hidden content, is announced as "link" and nothing else. The person hearing it cannot tell where it goes.

Text, an expression, a visible element, a `title` or an `aria-label` all count as content. A link that is itself hidden with `aria-hidden` is not checked.

If the only child is a hidden element, `--fix` removes its `aria-hidden` and `hidden` attributes.

## Examples

Reported:

{/* bad {"count": 2} */}

```jsx
const profile = <a href="/profile" />;
const settings = (
  <a href="/settings">
    <span aria-hidden>Settings</span>
  </a>
);
```

Not reported:

{/* good */}

```jsx
const profile = <a href="/profile">{user.name}</a>;
const settings = (
  <a href="/settings">
    <span>Settings</span>
  </a>
);
const close = (
  <a href="/" aria-label="Close">
    <Icon name="x" aria-hidden />
  </a>
);
```

## Options

| Option       | Default | What it does                  |
| ------------ | ------- | ----------------------------- |
| `components` | `[]`    | Components to check like `a`. |

{/* bad {"options": [{"components": ["Link"]}]} */}

```jsx
const profile = <Link to="/profile" />;
```
