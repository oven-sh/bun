---
title: "jsx-a11y/iframe-has-title"
description: "Require a `title` on `iframe` elements"
---

A screen reader announces an `iframe` by its `title`. Without one, it reads the URL or says "frame", and the person has to go into the frame to find out whether it is a video, a map or an ad.

An empty string, `null`, `undefined`, a number, `true` and `false` do not count as a title. Neither does a spread: `<iframe {...props} />` is reported even if `props` has a `title`.

## Examples

Reported:

{/* bad {"count": 3} */}

```jsx
const map = <iframe src={mapUrl} />;
const video = <iframe src={videoUrl} title="" />;
const widget = <iframe {...frameProps} />;
```

Not reported:

{/* good */}

```jsx
const map = <iframe src={mapUrl} title="Map of our offices" />;
const video = <iframe src={videoUrl} title={clip.name} />;
const widget = <iframe {...frameProps} title={`Preview of ${page.name}`} />;
```

A title put together with `+`, or read through `?.`, is also reported. Use a template or a variable:

{/* bad {"count": 2} */}

```jsx
const map = <iframe src={mapUrl} title={"Map of " + city} />;
const video = <iframe src={videoUrl} title={clip?.name} />;
```

{/* good */}

```jsx
const map = <iframe src={mapUrl} title={`Map of ${city}`} />;
const video = <iframe src={videoUrl} title={clipName} />;
```
