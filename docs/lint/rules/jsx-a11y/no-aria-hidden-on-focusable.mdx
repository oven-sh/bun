---
title: "jsx-a11y/no-aria-hidden-on-focusable"
description: 'Disallow `aria-hidden="true"` on elements that can receive focus'
---

`aria-hidden="true"` hides an element from screen readers, but the Tab key still stops on it. The user lands on something that is not announced and cannot tell where the focus went.

An element counts as focusable if its `tabIndex` is 0 or more. Without a `tabIndex`, these are focusable: `<a>` and `<area>` with an `href`, and `<button>`, `<input>`, `<select>` and `<textarea>` that are not `disabled`.

`--fix` removes the `aria-hidden` attribute.

## Examples

Reported:

{/* bad */}

```jsx
const close = <button aria-hidden="true" onClick={closeDialog} />;
```

{/* bad */}

```jsx
const panel = <div aria-hidden="true" tabIndex={0} />;
```

Not reported:

{/* good */}

```jsx
const close = <button aria-label="Close" onClick={closeDialog} />;
const icon = <svg aria-hidden="true" />;
const skipped = <button aria-hidden="true" tabIndex={-1} />;
```

Only `aria-hidden` and `aria-hidden="true"` are recognized. A value in braces is not checked:

{/* good */}

```jsx
const close = <button aria-hidden={true} onClick={closeDialog} />;
```
