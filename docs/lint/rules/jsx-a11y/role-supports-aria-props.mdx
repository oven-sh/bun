---
title: "jsx-a11y/role-supports-aria-props"
description: "Disallow `aria-*` attributes that the element's role does not support"
---

Each ARIA role supports a fixed set of `aria-*` attributes. A link cannot be checked and a list cannot be expanded. A screen reader ignores an attribute that does not fit the role, or announces something that makes no sense, so the state you meant to tell the user is lost.

The role is the one in the `role` attribute. Without it, the rule uses the role that the element has by itself: `link` for `<a href>`, `list` for `<ul>`, `heading` for `<h1>`. An element or a component that has no role either way, such as a plain `<div>`, is not reported.

## Examples

Reported:

{/* bad */}

```jsx
const filter = (
  <a href="/sale" aria-checked={onSale}>
    On sale
  </a>
);
```

{/* bad */}

```jsx
const items = <ul aria-expanded={isOpen} />;
```

{/* bad */}

```jsx
const save = <div role="button" aria-required="true" />;
```

Not reported:

{/* good */}

```jsx
const filter = <input type="checkbox" aria-checked={onSale} />;
const toggle = <button aria-expanded={isOpen}>Items</button>;
const items = <ul aria-label="Items" />;
const panel = <div aria-expanded={isOpen} />;
```
