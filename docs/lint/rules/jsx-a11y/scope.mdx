---
title: "jsx-a11y/scope"
description: "Disallow the `scope` attribute on elements other than `<th>`"
---

`scope` tells a screen reader whether a header cell names its column or its row. It only has a meaning on `<th>`. On a `<td>` or anything else it is ignored, so the cell you meant as a header is read as ordinary data.

Components are not checked.

`--fix` removes the attribute.

## Examples

Reported:

{/* bad */}

```jsx
const row = (
  <tr>
    <td scope="row">Total</td>
    <td>{total}</td>
  </tr>
);
```

Not reported:

{/* good */}

```jsx
const row = (
  <tr>
    <th scope="row">Total</th>
    <td>{total}</td>
  </tr>
);
```
