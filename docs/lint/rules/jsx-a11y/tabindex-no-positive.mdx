---
title: "jsx-a11y/tabindex-no-positive"
description: "Disallow `tabIndex` values greater than 0"
---

The Tab key visits every element with a positive `tabIndex` first, from the lowest number to the highest, and only then the rest of the page. The focus jumps around in an order that does not match what is on the screen, and every new control means renumbering the others.

Use `0` to put an element in the tab order at its place in the document, and `-1` to make it focusable from code only. To change the order, move the elements.

Your editor can change the value to `"0"` as a suggestion. A value that is only known at run time, such as `tabIndex={order}`, is not checked.

## Examples

Reported:

{/* bad {"count": 2} */}

```jsx
const form = (
  <form>
    <input name="email" tabIndex={2} />
    <input name="name" tabIndex="1" />
  </form>
);
```

Not reported:

{/* good */}

```jsx
const form = (
  <form>
    <input name="name" />
    <input name="email" />
    <div role="button" tabIndex={0} />
    <h2 tabIndex={-1}>Done</h2>
  </form>
);
```
