---
title: "@next/next/no-title-in-document-head"
description: "Disallow `<title>` in the `Head` of `next/document`"
---

`pages/_document.js` is shared by all pages, so a `<title>` in it gives every page the same title, and it can clash with the title a page sets for itself. Set the title in each page, with `Head` from `next/head`.

The rule reports a `<title>` that is a direct child of the `Head` you import from `next/document`.

## Examples

Reported:

{/* bad {"filename": "pages/_document.jsx"} */}

```jsx
import { Head, Html, Main, NextScript } from "next/document";

export default function Document() {
  return (
    <Html>
      <Head>
        <title>My shop</title>
      </Head>
      <body>
        <Main />
        <NextScript />
      </body>
    </Html>
  );
}
```

Not reported, in a page:

{/* good {"filename": "pages/index.jsx"} */}

```jsx
import Head from "next/head";

export default function Home() {
  return (
    <Head>
      <title>My shop</title>
    </Head>
  );
}
```

The rule only follows the first name in the braces of the import. If `Head` is not first, nothing is reported:

{/* good {"filename": "pages/_document.jsx"} */}

```jsx
import { Html, Head } from "next/document";

export default function Document() {
  return (
    <Html>
      <Head>
        <title>My shop</title>
      </Head>
    </Html>
  );
}
```
