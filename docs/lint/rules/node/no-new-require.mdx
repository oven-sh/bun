---
title: "n/no-new-require"
description: "Disallow `new require()`"
---

`new require("./app")` applies `new` to `require`, not to what `require` returns. You get the class that the module exports, not an instance of it.

## Examples

Reported:

{/* bad */}

```js
const app = new require("./app");
```

Not reported:

{/* good */}

```js
const App = require("./app");
const app = new App();
```

With parentheses around the `require()` call, `new` applies to the class:

{/* good */}

```js
const app = new (require("./app"))();
```
