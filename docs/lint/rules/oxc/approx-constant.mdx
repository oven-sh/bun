---
title: "oxc/approx-constant"
description: "Disallow numbers that approximate a constant of the `Math` object"
---

`3.14159` typed by hand is less precise than `Math.PI`, and the reader has to recognize the digits to know what it is.

The rule reports a number with at least three decimals that is `Math.E`, `Math.LN10`, `Math.LN2`, `Math.LOG2E`, `Math.LOG10E`, `Math.PI`, `Math.SQRT1_2` or `Math.SQRT2`, cut off or rounded. `3.14` is too short to count.

`--fix-suggestions` replaces the number with the constant.

## Examples

Reported:

{/* bad {"count": 2} */}

```js
function circleArea(radius) {
  return 3.14159 * radius * radius;
}

const diagonal = side * 1.4142;
```

Not reported:

{/* good */}

```js
function circleArea(radius) {
  return Math.PI * radius * radius;
}

const diagonal = side * Math.SQRT2;
const price = 3.14;
```
