---
title: "oxc/bad-object-literal-comparison"
description: "Disallow comparing a value with `{}` or `[]`"
---

`items === []` does not test whether `items` is empty. Each `[]` or `{}` creates a new object, and `===` compares objects by identity, so the comparison is always `false` and `!==` is always `true`.

The rule reports `==`, `!=`, `===` and `!==` with an empty object or array literal on either side. To test for empty, look at `length` or at the keys.

## Examples

Reported:

{/* bad {"count": 2} */}

```js
if (items === []) {
  showPlaceholder();
}

if (filters !== {}) {
  applyFilters(filters);
}
```

Not reported:

{/* good */}

```js
if (items.length === 0) {
  showPlaceholder();
}

if (Object.keys(filters).length > 0) {
  applyFilters(filters);
}
```
