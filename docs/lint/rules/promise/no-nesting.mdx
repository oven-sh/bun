---
title: "promise/no-nesting"
description: "Disallow `then()` and `catch()` nested inside another `then()` or `catch()`"
---

A `then()` inside a `then()` adds a level of indentation for every step, and a `catch()` on the inner chain does not see errors from the outer one. Return the inner promise and continue the chain one level up.

A nested callback that uses a variable of the outer callback cannot move up, so it is not reported.

## Examples

Reported:

{/* bad */}

```js
getUser(id).then(user => {
  return getOrders(user).then(orders => render(orders));
});
```

Not reported:

{/* good */}

```js
getUser(id)
  .then(user => getOrders(user))
  .then(orders => render(orders));
```

Here the inner callback needs `user`:

{/* good */}

```js
getUser(id).then(user => {
  return getOrders(user).then(orders => render(user, orders));
});
```
