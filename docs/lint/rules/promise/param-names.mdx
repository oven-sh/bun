---
title: "promise/param-names"
description: "Require the parameters of a `new Promise()` executor to be named `resolve` and `reject`"
---

The function given to `new Promise()` gets its two parameters by position, whatever you call them. If you write them in the wrong order, `reject(value)` fulfills the promise and `resolve(error)` rejects it.

The first parameter must be `resolve` or `_resolve`, the second `reject` or `_reject`. You can leave out parameters you do not use.

## Examples

Reported:

{/* bad {"count": 2} */}

```js
new Promise((reject, resolve) => {
  setTimeout(resolve, 1000); // rejects the promise
});
```

{/* bad */}

```js
new Promise(done => {
  setTimeout(done, 1000);
});
```

Not reported:

{/* good */}

```js
new Promise(resolve => {
  setTimeout(resolve, 1000);
});

new Promise((_resolve, reject) => {
  setTimeout(reject, 1000);
});
```

## Options

| Option           | Default         | What it does                                                      |
| ---------------- | --------------- | ----------------------------------------------------------------- |
| `resolvePattern` | `"^_?resolve$"` | A regular expression that the first parameter's name must match.  |
| `rejectPattern`  | `"^_?reject$"`  | A regular expression that the second parameter's name must match. |

{/* good {"options": [{"resolvePattern": "^(resolve|done)$", "rejectPattern": "^(reject|fail)$"}]} */}

```js
new Promise((done, fail) => {
  socket.once("open", done);
  socket.once("error", fail);
});
```
