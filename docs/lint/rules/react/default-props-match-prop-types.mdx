---
title: "react/default-props-match-prop-types"
description: "Require every entry of `defaultProps` to have a prop type that is not required"
---

A default for a required prop is a contradiction: either the caller must pass the prop, and the default is dead code, or the prop is optional, and its type is wrong. A default for a prop that is not declared at all is often a typo or a leftover from a rename.

The prop types can be `propTypes` or a TypeScript type. A component that declares no prop types is not checked.

## Examples

Reported:

{/* bad {"count": 2} */}

```jsx
function Greeting({ name, greeting }) {
  return (
    <p>
      {greeting}, {name}
    </p>
  );
}
Greeting.propTypes = {
  name: PropTypes.string.isRequired,
  greeting: PropTypes.string,
};
Greeting.defaultProps = {
  name: "friend", // required, so never used
  greting: "Hello", // no such prop
};
```

{/* bad */}

```tsx
function Greeting(props: { name: string; greeting?: string }) {
  return (
    <p>
      {props.greeting}, {props.name}
    </p>
  );
}
Greeting.defaultProps = { name: "friend" };
```

Not reported:

{/* good */}

```jsx
function Greeting({ name, greeting }) {
  return (
    <p>
      {greeting}, {name}
    </p>
  );
}
Greeting.propTypes = {
  name: PropTypes.string.isRequired,
  greeting: PropTypes.string,
};
Greeting.defaultProps = {
  greeting: "Hello",
};
```

## Options

| Option                  | Default | What it does                                                                          |
| ----------------------- | ------- | ------------------------------------------------------------------------------------- |
| `allowRequiredDefaults` | `false` | Allow a default for a required prop. A default without a prop type is still reported. |

{/* good {"options": [{"allowRequiredDefaults": true}]} */}

```jsx
function Greeting({ name }) {
  return <p>Hello, {name}</p>;
}
Greeting.propTypes = { name: PropTypes.string.isRequired };
Greeting.defaultProps = { name: "friend" };
```
