---
title: "react-hooks/exhaustive-deps"
description: "Require the dependency array of a hook to list every value its callback reads"
---

React runs an effect again, or recomputes a memoized value, only when something in the dependency array changes. If the callback reads a prop or a state value that is not in the array, it keeps the value from an earlier render: the effect does not run again when the prop changes, and the screen shows old data.

The rule checks `useEffect`, `useLayoutEffect`, `useMemo`, `useCallback`, and `useImperativeHandle`. It also reports dependencies that do nothing, dependency lists it cannot read, and an `async` function passed to an effect. Values that never change between renders need not be listed: a `setState` function, a `dispatch` from `useReducer`, a ref from `useRef`, and anything declared outside the component.

This rule is on by default, as a warning, in files with JSX in a project that depends on `react`.

Most reports come with a suggestion that rewrites the array, which your editor can apply. `--fix` does not apply it.

## Examples

Reported:

{/* bad */}

```jsx
function Profile({ userId }) {
  const [user, setUser] = useState(null);

  useEffect(() => {
    loadUser(userId).then(setUser);
  }, []); // keeps showing the first user when userId changes

  return <h1>{user?.name}</h1>;
}
```

{/* bad */}

```jsx
function Profile({ userId }) {
  useEffect(async () => {
    await track(userId);
  }, [userId]);
}
```

Not reported:

{/* good */}

```jsx
function Profile({ userId }) {
  const [user, setUser] = useState(null);

  useEffect(() => {
    loadUser(userId).then(setUser);
  }, [userId]);

  return <h1>{user?.name}</h1>;
}
```

An effect without an array runs after every render, so there is nothing to check:

{/* good */}

```jsx
function Title({ text }) {
  useEffect(() => {
    document.title = text;
  });
}
```

## Options

| Option                                            | Default | What it does                                                                                              |
| ------------------------------------------------- | ------- | --------------------------------------------------------------------------------------------------------- |
| `additionalHooks`                                 |         | A regular expression for the names of your own hooks that take a callback and a dependency array.         |
| `requireExplicitEffectDeps`                       | `false` | Report an effect that has no second argument. Write `undefined` to say "after every render" on purpose.   |
| `enableDangerousAutofixThisMayCauseInfiniteLoops` | `false` | Let `--fix` apply the suggestions. A new dependency can make an effect run in a loop, so read the result. |
| `experimental_autoDependenciesHooks`              | `[]`    | Names of hooks that get their dependencies from a compiler when you pass `null`.                          |

{/* bad {"options": [{"additionalHooks": "^useDebouncedEffect$"}]} */}

```jsx
function Search({ query }) {
  useDebouncedEffect(() => {
    search(query);
  }, []);
}
```

{/* bad {"options": [{"requireExplicitEffectDeps": true}]} */}

```jsx
function Title({ text }) {
  useEffect(() => {
    document.title = text;
  });
}
```
