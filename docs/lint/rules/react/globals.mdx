---
title: "react-hooks/globals"
description: "Disallow reassigning variables declared outside a component or hook during render"
---

React decides when and how often a component renders. In development, Strict Mode renders it twice. If rendering assigns to a variable that lives outside the component, the value of that variable depends on how many times React happened to render.

An assignment in an effect or in an event handler is allowed, because that code does not run during render.

## Examples

Reported:

{/* bad */}

```jsx
let renderCount = 0;

function Counter() {
  renderCount = renderCount + 1;
  return <div>Rendered {renderCount} times</div>;
}
```

A function that is called during render counts too:

{/* bad */}

```jsx
let total = 0;

function Cart({ items }) {
  const add = item => {
    total = total + item.price;
  };
  items.forEach(add);
  return <div>{total}</div>;
}
```

Not reported:

{/* good */}

```jsx
function Cart({ items }) {
  let total = 0;
  for (const item of items) {
    total = total + item.price;
  }
  return <div>{total}</div>;
}
```

{/* good */}

```jsx
import { useEffect } from "react";

let mountedPages = 0;
let lastClicked = null;

function Page({ id }) {
  useEffect(() => {
    mountedPages = mountedPages + 1;
  }, []);
  return (
    <button
      onClick={() => {
        lastClicked = id;
      }}
    >
      Open
    </button>
  );
}
```

Changing a property of an outside object, as in `config.theme = "dark"`, is not reported by this rule. `react-hooks/immutability` reports it.

{/* good */}

```jsx
const config = { theme: "light" };

function Page() {
  config.theme = "dark";
  return <div className={config.theme} />;
}
```
