---
title: "react/jsx-closing-bracket-location"
description: "Enforce where the closing bracket of a multiline JSX tag goes"
---

When the props of a JSX tag are spread over several lines, the closing `>` or `/>` can end up in several places. This rule keeps it in one. By default the bracket goes on its own line, in the same column as the `<` that opens the tag.

If the tag has no props, or the tag and its last prop are on one line, the bracket must be on that line too, whatever the options say.

`--fix` moves the bracket.

## Examples

Reported:

{/* bad */}

```jsx
const button = <Button label="Save" onClick={save} />;
```

{/* bad {"count": 2} */}

```jsx
const button = <Button label="Save" />;

const divider = <Divider />;
```

Not reported:

{/* good */}

```jsx
const button = <Button label="Save" onClick={save} />;

const small = <Button label="Save" />;
```

## Options

```toml bunfig.toml
[lint.rules]
"react/jsx-closing-bracket-location" = ["error", "line-aligned"]
```

| Option                    | Where the bracket goes                                                      |
| ------------------------- | --------------------------------------------------------------------------- |
| `"tag-aligned"` (default) | On its own line, in the column of the opening `<`.                          |
| `"line-aligned"`          | On its own line, with the indentation of the line that has the opening `<`. |
| `"props-aligned"`         | On its own line, in the column of the last prop.                            |
| `"after-props"`           | On the same line as the last prop.                                          |

`"line-aligned"` differs from `"tag-aligned"` when the tag does not start its line:

{/* good {"options": ["line-aligned"]} */}

```jsx
const button = <Button label="Save" onClick={save} />;
```

{/* bad {"options": ["tag-aligned"]} */}

```jsx
const button = <Button label="Save" onClick={save} />;
```

{/* good {"options": ["props-aligned"]} */}

```jsx
const button = <Button label="Save" onClick={save} />;
```

{/* good {"options": ["after-props"]} */}

```jsx
const button = <Button label="Save" onClick={save} />;
```

The option can also be an object:

| Option        | What it does                                                                         |
| ------------- | ------------------------------------------------------------------------------------ |
| `location`    | One of the four values above, for all tags.                                          |
| `selfClosing` | The location for tags that end in `/>`. `false` turns the check off for them.        |
| `nonEmpty`    | The location for tags that have a closing tag. `false` turns the check off for them. |

{/* good {"options": [{"selfClosing": "after-props", "nonEmpty": "tag-aligned"}]} */}

```jsx
const form = (
  <Form onSubmit={save}>
    <Button label="Save" />
  </Form>
);
```

## When not to use it

A formatter such as Prettier already decides where the bracket goes. If you use one, turn this rule off.
