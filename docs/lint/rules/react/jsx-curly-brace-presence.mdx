---
title: "react/jsx-curly-brace-presence"
description: "Disallow curly braces around plain strings in JSX, or require them"
---

`<Button label={"Save"} />` and `<Button label="Save" />` mean the same thing, and so do `<p>{"Hello"}</p>` and `<p>Hello</p>`. The braces add noise. By default this rule reports them around a plain string, around a template literal without `${}`, and around an element that is a child.

Braces that are needed stay. A string is left alone if it is only white space, as in `{" "}`, or if it has something that JSX reads differently from JavaScript: a backslash, a line break, or an entity such as `&amp;`. In a child, a string is also left alone if it starts or ends with white space, has `<`, `>`, `{`, or `}`, or stands next to another `{}` expression.

`--fix` removes or adds the braces.

## Examples

Reported:

{/* bad {"count": 3} */}

```jsx
const button = <Button label={"Save"}>{"Save"}</Button>;

const panel = <Panel>{<Spinner />}</Panel>;
```

Not reported:

{/* good */}

```jsx
const button = <Button label="Save">Save</Button>;

const panel = (
  <Panel>
    <Spinner />
  </Panel>
);

const kept = (
  <ul title={`Hello ${name}`}>
    <li> </li>
    <li>{"a\tb"}</li>
    <li>{"&amp;"}</li>
    <li>{"{braces}"}</li>
    <li>{"Total: "}</li>
    <li>
      {"Hello"}
      {name}
    </li>
  </ul>
);
```

## Options

| Option              | Default    | What it does                                                |
| ------------------- | ---------- | ----------------------------------------------------------- |
| `props`             | `"never"`  | Braces around a string that is the value of an attribute.   |
| `children`          | `"never"`  | Braces around a string or an element that is a child.       |
| `propElementValues` | `"ignore"` | Braces around an element that is the value of an attribute. |

Each takes `"never"` (report the braces), `"always"` (report a string without braces), or `"ignore"` (do not check). One of these words in place of the object sets both `props` and `children`.

{/* bad {"options": ["always"], "count": 2} */}

```jsx
const button = <Button label="Save">Save</Button>;
```

{/* good {"options": ["always"]} */}

```jsx
const button = <Button label={"Save"}>{"Save"}</Button>;
```

{/* good {"options": [{"children": "ignore"}]} */}

```jsx
const greeting = <p>{"Hello"}</p>;
```

{/* bad {"options": [{"propElementValues": "always"}]} */}

```jsx
const page = <Layout header=<Header /> />;
```

{/* good {"options": [{"propElementValues": "always"}]} */}

```jsx
const page = <Layout header={<Header />} />;
```

`propElementValues: "never"` reports the element with braces, and it also reports the element without them. Nothing you write passes, so use `"always"` or `"ignore"`.

{/* bad {"options": [{"propElementValues": "never"}], "count": 2} */}

```jsx
const page = <Layout header={<Header />} />;

const other = <Layout header=<Header /> />;
```
