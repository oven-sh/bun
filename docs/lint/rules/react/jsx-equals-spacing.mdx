---
title: "react/jsx-equals-spacing"
description: "Enforce or disallow spaces around the `=` of JSX attributes"
---

`name="email"` and `name = "email"` mean the same. Choosing one keeps attributes easy to scan. By default the rule allows no space on either side of the `=`.

`--fix` adds or removes the spaces.

## Examples

Reported:

{/* bad {"count": 2} */}

```jsx
const field = <input name="email" />;
```

Not reported:

{/* good */}

```jsx
const field = <input name="email" required />;
```

## Options

| Option              | What it does                              |
| ------------------- | ----------------------------------------- |
| `"never"` (default) | Allow no space before or after the `=`.   |
| `"always"`          | Require a space before and after the `=`. |

{/* bad {"options": ["always"]} */}

```jsx
const field = <input name="email" />;
```

{/* good {"options": ["always"]} */}

```jsx
const field = <input name="email" />;
```
