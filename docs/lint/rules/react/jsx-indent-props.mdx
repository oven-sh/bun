---
title: "react/jsx-indent-props"
description: "Enforce consistent indentation of JSX props"
---

When the props of a tag are on lines of their own, their indentation is what sets them apart from the tag's children. The rule checks each prop that starts a line. The default is 4 spaces more than the line where the tag starts.

`--fix` corrects the indentation.

## Examples

Reported:

{/* bad {"count": 2} */}

```jsx
const field = <Input name="email" value={email} />;
```

Not reported:

{/* good */}

```jsx
const field = <Input name="email" value={email} />;
```

## Options

The option is a number of spaces, `"tab"`, `"first"`, or an object:

| Option                  | Default | What it does                                                                                                  |
| ----------------------- | ------- | ------------------------------------------------------------------------------------------------------------- |
| `indentMode`            | `4`     | A number of spaces, `"tab"` for one tab, or `"first"` to line up every prop with the first one.               |
| `ignoreTernaryOperator` | `false` | By default, props of a tag on a line that starts with `?` or `:` get one more level. With `true` they do not. |

```toml bunfig.toml
[lint.rules]
"react/jsx-indent-props" = ["error", 2]
```

{/* good {"options": [2]} */}

```jsx
const field = <Input name="email" value={email} />;
```

With `"first"`:

{/* bad {"options": ["first"]} */}

```jsx
const field = <Input name="email" value={email} />;
```

{/* good {"options": ["first"]} */}

```jsx
const field = <Input name="email" value={email} />;
```

A tag after `?` or `:` at the start of a line:

{/* good {"options": [2]} */}

```jsx
const field = editable ? <Input name="email" /> : null;
```

{/* bad {"options": [2]} */}

```jsx
const field = editable ? <Input name="email" /> : null;
```

{/* good {"options": [{"indentMode": 2, "ignoreTernaryOperator": true}]} */}

```jsx
const field = editable ? <Input name="email" /> : null;
```

## When not to use it

If `bun format` or another formatter lays out your code, it already decides the indentation.
