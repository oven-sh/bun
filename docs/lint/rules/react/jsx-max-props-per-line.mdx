---
title: "react/jsx-max-props-per-line"
description: "Enforce a maximum number of props on one line of a JSX tag"
---

A long row of props is hard to scan, and a change to one of them marks the whole line in a diff. By default the rule allows one prop on a line.

`--fix` puts the extra props on new lines.

## Examples

Reported:

{/* bad */}

```jsx
const field = <Input name="email" value={email} />;
```

Not reported:

{/* good */}

```jsx
const field = <Input name="email" value={email} />;

const short = <Input name="email" />;
```

## Options

| Option    | Default    | What it does                                                 |
| --------- | ---------- | ------------------------------------------------------------ |
| `maximum` | `1`        | How many props a line can have.                              |
| `when`    | `"always"` | With `"multiline"`, only check tags that take several lines. |

`maximum` can also be an object with a limit for tags on one line and a limit for tags that take several lines: `{ single, multi }`. A limit that you leave out is not checked. Do not combine it with `when`.

```toml bunfig.toml
[lint.rules]
"react/jsx-max-props-per-line" = ["error", { maximum = { single = 3, multi = 1 } }]
```

{/* good {"options": [{"maximum": 2}]} */}

```jsx
const field = <Input name="email" value={email} />;
```

{/* good {"options": [{"when": "multiline"}]} */}

```jsx
const field = <Input name="email" value={email} />;
```

{/* bad {"options": [{"when": "multiline"}]} */}

```jsx
const field = <Input name="email" value={email} />;
```

{/* good {"options": [{"maximum": {"single": 3, "multi": 1}}]} */}

```jsx
const short = <Input name="email" value={email} required />;

const long = <Input name="email" value={email} />;
```

{/* good {"options": [{"maximum": {"multi": 1}}]} */}

```jsx
const short = <Input name="email" value={email} required disabled />;
```
