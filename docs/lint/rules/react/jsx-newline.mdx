---
title: "react/jsx-newline"
description: "Require or disallow an empty line between JSX elements and expressions"
---

An empty line between siblings sets apart the blocks of a long JSX tree. Some teams want it everywhere, others nowhere. By default the rule requires an empty line before each element or `{...}` expression that follows another one.

`--fix` adds or removes the empty line.

## Examples

Reported:

{/* bad {"count": 2} */}

```jsx
const page = (
  <main>
    <Header />
    <Content />
    {footer}
  </main>
);
```

Not reported:

{/* good */}

```jsx
const page = (
  <main>
    <Header />

    <Content />

    {footer}
  </main>
);
```

## Options

| Option            | Default | What it does                                                                                                    |
| ----------------- | ------- | --------------------------------------------------------------------------------------------------------------- |
| `prevent`         | `false` | Report the empty lines instead of requiring them.                                                               |
| `allowMultilines` | `false` | Only together with `prevent`. Still require an empty line before and after an element that takes several lines. |

{/* bad {"options": [{"prevent": true}]} */}

```jsx
const page = (
  <main>
    <Header />

    <Content />
  </main>
);
```

{/* good {"options": [{"prevent": true}]} */}

```jsx
const page = (
  <main>
    <Header />
    <Content />
  </main>
);
```

{/* good {"options": [{"prevent": true, "allowMultilines": true}]} */}

```jsx
const page = (
  <main>
    <Header />
    <Nav />

    <Content>
      <Article />
    </Content>

    <Footer />
  </main>
);
```

{/* bad {"options": [{"prevent": true, "allowMultilines": true}]} */}

```jsx
const page = (
  <main>
    <Header />
    <Content>
      <Article />
    </Content>
  </main>
);
```
