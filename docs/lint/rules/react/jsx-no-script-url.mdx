---
title: "react/jsx-no-script-url"
description: "Disallow `javascript:` URLs in links"
---

A `javascript:` URL runs its text as code when the link is followed. That is a common way to inject a script into a page, and React plans to block these URLs. Use an event handler instead.

By default the rule looks at the `href` of `<a>`. It only sees URLs written as a plain string, not values in braces.

## Examples

Reported:

{/* bad */}

```jsx
const close = <a href="javascript:closeDialog()">Close</a>;
```

Not reported:

{/* good */}

```jsx
const close = <button onClick={closeDialog}>Close</button>;

const home = <a href="/home">Home</a>;
```

## Options

The first option is a list of your own link components and the props that hold a URL:

```toml bunfig.toml
[lint.rules]
"react/jsx-no-script-url" = ["error", [{ name = "Link", props = ["to"] }]]
```

{/* bad {"options": [[{"name": "Link", "props": ["to"]}]]} */}

```jsx
const close = <Link to="javascript:closeDialog()">Close</Link>;
```

Other props of that component are not checked:

{/* good {"options": [[{"name": "Link", "props": ["to"]}]]} */}

```jsx
const close = <Link label="javascript:closeDialog()">Close</Link>;
```

After the list, or in its place, comes an object:

| Option                | Default | What it does                                                                                     |
| --------------------- | ------- | ------------------------------------------------------------------------------------------------ |
| `includeFromSettings` | `false` | Also check the components listed under `linkComponents` in the `settings` of your ESLint config. |
