---
title: "react/jsx-props-no-spread-multi"
description: "Disallow spreading the same variable twice in one JSX element"
---

The second spread of the same object adds nothing new, and it overwrites every prop written between the two. In `<Button {...props} disabled {...props} />`, `disabled` is lost if `props` has a `disabled` of its own. It is almost always a leftover from a merge or a copy.

## Examples

Reported:

{/* bad */}

```jsx
function SaveButton(props) {
  return <Button {...props} type="submit" {...props} />;
}
```

Not reported:

{/* good */}

```jsx
function SaveButton(props) {
  return <Button {...props} type="submit" />;
}

function Field({ input, meta }) {
  return <Input {...input} {...meta} />;
}
```
