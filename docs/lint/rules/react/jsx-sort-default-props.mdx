---
title: "react/jsx-sort-default-props"
description: "Require the keys of `defaultProps` to be sorted alphabetically"
---

In a long `defaultProps` object, a fixed order makes a prop quick to find and makes a duplicate stand out.

This is the old name of `react/sort-default-props`, which does the same. Use that name in new configs.

Capital letters sort before lowercase ones. After a spread, sorting starts over.

## Examples

Reported:

{/* bad */}

```jsx
function Button({ label, size }) {
  return <button className={size}>{label}</button>;
}

Button.defaultProps = {
  size: "medium",
  label: "OK",
};
```

Not reported:

{/* good */}

```jsx
function Button({ label, size }) {
  return <button className={size}>{label}</button>;
}

Button.defaultProps = {
  label: "OK",
  size: "medium",
};
```

{/* good */}

```jsx
class Button extends React.Component {
  static defaultProps = {
    size: "medium",
    ...shared,
    label: "OK",
  };
}
```

## Options

| Option       | Default | What it does                             |
| ------------ | ------- | ---------------------------------------- |
| `ignoreCase` | `false` | Compare the keys without regard to case. |

{/* bad */}

```jsx
Button.defaultProps = {
  ariaLabel: "",
  Icon: null,
};
```

{/* good {"options": [{"ignoreCase": true}]} */}

```jsx
Button.defaultProps = {
  ariaLabel: "",
  Icon: null,
};
```
