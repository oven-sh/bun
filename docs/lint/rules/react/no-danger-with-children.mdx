---
title: "react/no-danger-with-children"
description: "Disallow `dangerouslySetInnerHTML` on an element that also has children"
---

`dangerouslySetInnerHTML` replaces everything inside an element, so it cannot be combined with children. React throws an error when it renders a DOM element that has both.

Children count whether they are between the tags, in a `children` prop, or the third argument of `React.createElement`. Props that are spread from an object literal in a variable are followed.

## Examples

Reported:

{/* bad */}

```jsx
const article = <div dangerouslySetInnerHTML={{ __html: post.body }}>Loading</div>;
```

{/* bad {"count": 2} */}

```jsx
const props = { dangerouslySetInnerHTML: { __html: post.body } };

const article = <div {...props}>Loading</div>;

const summary = React.createElement("div", props, "Loading");
```

Not reported:

{/* good */}

```jsx
const article = <div dangerouslySetInnerHTML={{ __html: post.body }} />;

const placeholder = <div>Loading</div>;
```

A line break between the tags is not a child:

{/* good */}

```jsx
const article = <div dangerouslySetInnerHTML={{ __html: post.body }}></div>;
```
