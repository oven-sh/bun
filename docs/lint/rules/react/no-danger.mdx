---
title: "react/no-danger"
description: "Disallow the `dangerouslySetInnerHTML` prop"
---

React escapes the text you render. `dangerouslySetInnerHTML` turns that off and puts a string into the page as HTML. If any part of the string comes from a user, they can run scripts in the browsers of other users.

By default only DOM elements such as `<div>` are checked, not your own components.

## Examples

Reported:

{/* bad */}

```jsx
const comment = <div dangerouslySetInnerHTML={{ __html: post.body }} />;
```

Not reported:

{/* good */}

```jsx
const comment = <div>{post.body}</div>;

const preview = <Markdown dangerouslySetInnerHTML={{ __html: post.body }} />;
```

## Options

| Option                 | Default | What it does                                                                                                                             |
| ---------------------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `customComponentNames` | `[]`    | Names of components to check as well. A name can be a glob: `"*"` matches every component, `"Html*"` every name that starts with `Html`. |

{/* bad {"options": [{"customComponentNames": ["Markdown", "Html*"]}], "count": 2} */}

```jsx
const preview = <Markdown dangerouslySetInnerHTML={{ __html: post.body }} />;

const footer = <HtmlBlock dangerouslySetInnerHTML={{ __html: site.footer }} />;
```

## When not to use it

Some pages have to render HTML from a trusted or sanitized source, such as the output of a Markdown renderer. Disable the rule on those lines, so that each use stays visible in review.
