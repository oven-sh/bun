---
title: "react/no-object-type-as-default-prop"
description: "Disallow objects, arrays, and functions as default values of destructured props"
---

A default value in the parameter list is evaluated again on every render. `users = []` makes a new array each time, so the prop is never equal to its value from the last render. A `useEffect` or `useMemo` that depends on it runs on every render, and a child wrapped in `memo` renders again every time. If the effect sets state, the component renders in a loop.

The rule looks at function components that destructure their props in the parameter list. It reports these defaults: an object, an array, a function, a class, a `new` expression, a regular expression, a JSX element, and a call to `Symbol()`. Strings, numbers, booleans, and names of variables are fine.

## Examples

Reported:

{/* bad {"count": 2} */}

```jsx
function UserList({ users = [], onSelect = () => {} }) {
  return (
    <ul>
      {users.map(user => (
        <li key={user.id} onClick={() => onSelect(user)}>
          {user.name}
        </li>
      ))}
    </ul>
  );
}
```

Not reported:

{/* good */}

```jsx
const noUsers = [];
const ignore = () => {};

function UserList({ users = noUsers, onSelect = ignore, limit = 10 }) {
  return (
    <ul>
      {users.slice(0, limit).map(user => (
        <li key={user.id} onClick={() => onSelect(user)}>
          {user.name}
        </li>
      ))}
    </ul>
  );
}
```

A function that is not a component is not checked:

{/* good */}

```jsx
function sortUsers({ users = [] }) {
  return users.toSorted((a, b) => a.name.localeCompare(b.name));
}
```
