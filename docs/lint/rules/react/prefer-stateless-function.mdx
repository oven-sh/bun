---
title: "react/prefer-stateless-function"
description: "Require class components that only render from props to be functions"
---

A class that has nothing but a `render` method that reads `this.props` does the same as a function that takes `props`, with more code around it.

A class is not reported if it needs to be one. That is the case if it uses `this.state`, another member of `this` besides `props` and `context`, a `ref` attribute, a lifecycle method or any other method, a decorator, or a constructor that does more than pass its arguments to `super`.

## Examples

Reported:

{/* bad */}

```jsx
class Greeting extends React.Component {
  render() {
    return <h1>Hello {this.props.name}</h1>;
  }
}
```

Not reported:

{/* good */}

```jsx
function Greeting(props) {
  return <h1>Hello {props.name}</h1>;
}

class Counter extends React.Component {
  state = { count: 0 };
  render() {
    return <button onClick={() => this.setState({ count: this.state.count + 1 })}>{this.state.count}</button>;
  }
}
```

## Options

| Option                 | Default | What it does                                                                                 |
| ---------------------- | ------- | -------------------------------------------------------------------------------------------- |
| `ignorePureComponents` | `false` | Allow classes that extend `PureComponent`, which skips a render when the props are the same. |

{/* bad */}

```jsx
class Avatar extends React.PureComponent {
  render() {
    return <img src={this.props.url} alt={this.props.name} />;
  }
}
```

{/* good {"options": [{"ignorePureComponents": true}]} */}

```jsx
class Avatar extends React.PureComponent {
  render() {
    return <img src={this.props.url} alt={this.props.name} />;
  }
}
```
