---
title: "react-hooks/rules-of-hooks"
description: "Require hooks to be called at the top level of a component or a custom hook"
---

React tells one `useState` from the next by the order of the calls. If a hook runs on one render and not on the next, every hook after it gets the state of another one, and React throws "Rendered fewer hooks than expected".

So a hook must be called on every render, in the same order. It cannot be in a condition, a loop, a nested function, or after an early `return`. It also cannot be in a class, an async function, at the top level of a file, or in a function that is neither a component nor a hook. A name counts as a hook if it is `use` or starts with `use` and a capital letter. A component's name starts with a capital letter.

This rule is on by default in files with JSX, if your `package.json` depends on `react`.

## Examples

Reported:

{/* bad */}

```jsx
function Profile({ user }) {
  if (user) {
    const [editing, setEditing] = useState(false);
  }
  return <p>{user?.name}</p>;
}
```

{/* bad */}

```jsx
function Profile({ user }) {
  if (!user) {
    return null;
  }
  const [editing, setEditing] = useState(false);
  return <p onClick={() => setEditing(!editing)}>{user.name}</p>;
}
```

{/* bad */}

```jsx
function List({ items }) {
  return items.map(item => {
    const id = useId();
    return <li key={id}>{item.name}</li>;
  });
}
```

{/* bad */}

```js
function loadTheme() {
  return useContext(ThemeContext);
}
```

Not reported:

{/* good */}

```jsx
function Profile({ user }) {
  const [editing, setEditing] = useState(false);
  if (!user) {
    return null;
  }
  return <p onClick={() => setEditing(!editing)}>{user.name}</p>;
}

function useTheme() {
  return useContext(ThemeContext);
}
```

`use` is the exception. It can be called in a condition or a loop, but not in a `try` block:

{/* good */}

```jsx
function Note({ notePromise }) {
  if (!notePromise) {
    return null;
  }
  const note = use(notePromise);
  return <p>{note.text}</p>;
}
```

A function made with `useEffectEvent` can only be called from an effect or another effect event in the same component:

{/* bad */}

```jsx
function Chat({ room }) {
  const onConnected = useEffectEvent(() => {
    notify(room);
  });
  return <button onClick={onConnected}>Connect</button>;
}
```
