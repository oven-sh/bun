---
title: "react/sort-prop-types"
description: "Require the keys of `propTypes` to be sorted alphabetically"
---

In a long `propTypes` object, a fixed order makes a prop quick to find and makes a duplicate stand out.

Capital letters sort before lowercase ones. After a spread, sorting starts over.

`--fix` sorts the keys.

## Examples

Reported:

{/* bad */}

```jsx
function Button({ label, size }) {
  return <button className={size}>{label}</button>;
}

Button.propTypes = {
  size: PropTypes.string,
  label: PropTypes.string,
};
```

Not reported:

{/* good */}

```jsx
function Button({ label, size }) {
  return <button className={size}>{label}</button>;
}

Button.propTypes = {
  label: PropTypes.string,
  size: PropTypes.string,
};
```

## Options

| Option                 | Default | What it does                                                                         |
| ---------------------- | ------- | ------------------------------------------------------------------------------------ |
| `ignoreCase`           | `false` | Compare the keys without regard to case.                                             |
| `requiredFirst`        | `false` | Require props marked `.isRequired` to come before the others.                        |
| `callbacksLast`        | `false` | Require props named like `onChange` to come after the others.                        |
| `noSortAlphabetically` | `false` | Do not check the alphabetical order. Use it with `requiredFirst` or `callbacksLast`. |
| `sortShapeProp`        | `false` | Also check the keys inside `PropTypes.shape({ ... })`.                               |
| `checkTypes`           | `false` | Also check the TypeScript type of the props of a function component.                 |

With `requiredFirst` and `callbacksLast`, each group is sorted alphabetically on its own:

{/* good {"options": [{"requiredFirst": true, "callbacksLast": true}]} */}

```jsx
Button.propTypes = {
  size: PropTypes.string.isRequired,
  label: PropTypes.string,
  theme: PropTypes.string,
  onClick: PropTypes.func,
};
```

{/* bad {"options": [{"requiredFirst": true}]} */}

```jsx
Button.propTypes = {
  label: PropTypes.string,
  size: PropTypes.string.isRequired,
};
```

{/* bad {"options": [{"callbacksLast": true}]} */}

```jsx
Button.propTypes = {
  label: PropTypes.string,
  onClick: PropTypes.func,
  size: PropTypes.string,
};
```

With `noSortAlphabetically`, only the groups matter:

{/* good {"options": [{"callbacksLast": true, "noSortAlphabetically": true}]} */}

```jsx
Button.propTypes = {
  size: PropTypes.string,
  label: PropTypes.string,
  onClick: PropTypes.func,
};
```

{/* bad {"options": [{"sortShapeProp": true}]} */}

```jsx
Profile.propTypes = {
  user: PropTypes.shape({
    name: PropTypes.string,
    email: PropTypes.string,
  }),
};
```

{/* bad {"options": [{"checkTypes": true}]} */}

```tsx
type ButtonProps = {
  size: string;
  label: string;
};

function Button(props: ButtonProps) {
  return <button className={props.size}>{props.label}</button>;
}
```
