---
title: "react/static-property-placement"
description: "Enforce where a class component declares `propTypes`, `defaultProps` and other static properties"
---

A class component can declare `propTypes` in three ways: as a `static` field, as a `static get` accessor, or by assigning to the class after its body. All three work. In a codebase that mixes them, you have to look in several places to find the props of a component.

The rule checks `propTypes`, `defaultProps`, `childContextTypes`, `contextTypes`, `contextType` and `displayName`. By default it asks for a `static` field. It does not look at function components.

## Examples

Reported:

{/* bad {"count": 2} */}

```jsx
class Button extends React.Component {
  static get defaultProps() {
    return { label: "OK" };
  }

  render() {
    return <button>{this.props.label}</button>;
  }
}

Button.propTypes = {
  label: PropTypes.string,
};
```

Not reported:

{/* good */}

```jsx
class Button extends React.Component {
  static propTypes = {
    label: PropTypes.string,
  };

  static defaultProps = {
    label: "OK",
  };

  render() {
    return <button>{this.props.label}</button>;
  }
}
```

{/* good */}

```jsx
function Button({ label }) {
  return <button>{label}</button>;
}

Button.propTypes = {
  label: PropTypes.string,
};
```

## Options

```toml bunfig.toml
[lint.rules]
"react/static-property-placement" = ["error", "property assignment"]
```

| Option                            | What it does                                                |
| --------------------------------- | ----------------------------------------------------------- |
| `"static public field"` (default) | Require `static propTypes = { ... }` in the class body.     |
| `"static getter"`                 | Require `static get propTypes() { ... }` in the class body. |
| `"property assignment"`           | Require `Button.propTypes = { ... }` after the class.       |

{/* bad {"options": ["property assignment"]} */}

```jsx
class Button extends React.Component {
  static propTypes = {
    label: PropTypes.string,
  };
}
```

{/* good {"options": ["static getter"]} */}

```jsx
class Button extends React.Component {
  static get propTypes() {
    return { label: PropTypes.string };
  }
}
```

A second option overrides the placement for individual properties. The keys are the six property names above:

{/* good {"options": ["static public field", {"propTypes": "property assignment"}]} */}

```jsx
class Button extends React.Component {
  static defaultProps = {
    label: "OK",
  };
}

Button.propTypes = {
  label: PropTypes.string,
};
```
