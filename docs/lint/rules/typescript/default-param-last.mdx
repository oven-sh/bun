---
title: "@typescript-eslint/default-param-last"
description: "Require parameters with a default value, and optional parameters, to come last"
---

A default value only applies when the argument is left out or is `undefined`. If a required parameter follows, the caller cannot leave the first one out and has to write `undefined` to get the default.

Optional parameters (`label?: string`) count like parameters with a default.

It is the TypeScript version of `default-param-last` and reports the same code. Turn on one of the two, not both.

## Examples

Reported:

{/* bad */}

```ts
function connect(port = 3000, host: string) {}

connect(undefined, "localhost");
```

{/* bad */}

```ts
function connect(port?: number, host: string) {}
```

{/* bad */}

```ts
class Client {
  constructor(
    private retries = 3,
    private url: string,
  ) {}
}
```

Not reported:

{/* good */}

```ts
function connect(host: string, port = 3000) {}

connect("localhost");
```

{/* good */}

```ts
function request(url: string, retries = 3, label?: string, ...headers: string[]) {}
```
