---
title: "@typescript-eslint/max-params"
description: "Enforce a maximum number of parameters in function definitions"
---

A call like `createUser("Ada", "ada@example.com", true, false)` says nothing about what each argument means, and two arguments of the same type can be swapped without an error. Past three parameters, one object with named properties is easier to read and to extend.

It is the TypeScript version of `max-params`. Function types are checked too. A `this: void` parameter is not counted.

## Examples

Reported:

{/* bad */}

```ts
function createUser(name: string, email: string, isAdmin: boolean, isActive: boolean) {
  return { name, email, isAdmin, isActive };
}
```

Not reported:

{/* good */}

```ts
interface NewUser {
  name: string;
  email: string;
  isAdmin: boolean;
  isActive: boolean;
}

function createUser(user: NewUser) {
  return { ...user };
}

function move(this: void, x: number, y: number, z: number) {}
```

## Options

| Option          | Default | What it does                                   |
| --------------- | ------- | ---------------------------------------------- |
| `max`           | `3`     | The number of parameters a function can have.  |
| `maximum`       |         | An older name for `max`.                       |
| `countVoidThis` | `false` | Count a `this: void` parameter like any other. |

{/* bad {"options": [{"max": 1}]} */}

```ts
type Add = (left: number, right: number) => number;
```

{/* bad {"options": [{"countVoidThis": true}]} */}

```ts
function move(this: void, x: number, y: number, z: number) {}
```

A `this` parameter of any other type is always counted:

{/* bad */}

```ts
function move(this: Window, x: number, y: number, z: number) {}
```
