---
title: "@typescript-eslint/parameter-properties"
description: "Require or disallow parameter properties in class constructors"
---

`constructor(private name: string) {}` declares a field and assigns it in one step. That is short, but the field is not listed with the other fields of the class, so it is easy to miss. It is also not plain type syntax, so tools that only strip types, such as Node.js, reject it.

By default, every parameter property is reported. The `prefer` option turns the rule around.

## Examples

Reported:

{/* bad */}

```ts
class User {
  constructor(private name: string) {}
}
```

Not reported:

{/* good */}

```ts
class User {
  private name: string;

  constructor(name: string) {
    this.name = name;
  }
}
```

## Options

| Option   | Default            | What it does                                                                                                                                       |
| -------- | ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `prefer` | `"class-property"` | `"parameter-property"` turns the rule around and reports fields that could be parameter properties.                                                |
| `allow`  | `[]`               | Modifiers to leave alone: `"readonly"`, `"private"`, `"protected"`, `"public"`, `"private readonly"`, `"protected readonly"`, `"public readonly"`. |

With `prefer: "parameter-property"`, a field is reported if it has no initial value, and the constructor starts by assigning it from a parameter with the same name and the same type:

{/* bad {"options": [{"prefer": "parameter-property"}]} */}

```ts
class User {
  private name: string;

  constructor(name: string) {
    this.name = name;
  }
}
```

{/* good {"options": [{"prefer": "parameter-property"}]} */}

```ts
class User {
  constructor(private name: string) {}
}
```

An entry of `allow` has to match all the modifiers. `"readonly"` allows `readonly id` and not `private readonly id`:

{/* good {"options": [{"allow": ["readonly"]}]} */}

```ts
class User {
  constructor(readonly id: number) {}
}
```

{/* bad {"options": [{"allow": ["readonly"]}]} */}

```ts
class User {
  constructor(private readonly id: number) {}
}
```
