---
title: "@typescript-eslint/prefer-nullish-coalescing"
description: "Require `??` instead of `||` or a ternary to give a default for `null` or `undefined`"
---

`port || 3000` falls back to `3000` for every falsy value, so a port of `0` is replaced, and so are `""` and `false`. `port ?? 3000` only falls back when `port` is `null` or `undefined`.

`||` and `||=` are reported when the type of the left side includes `null` or `undefined`. A ternary or an `if` that does by hand what `??` or `??=` does is reported too.

`--fix` does not change these. Look at each one before you change it: `??` keeps `0`, `""`, and `false` where `||` replaced them.

This rule needs type information. Run `bun lint --type-aware`. It also needs `strictNullChecks` (or `strict`) in your `tsconfig.json`.

## Examples

Reported:

{/* bad {"count": 4} */}

```ts
function connect(options: { port?: number; host: string | null; name?: string; tags?: string[] }) {
  const port = options.port || 3000;
  const host = options.host !== null ? options.host : "localhost";
  options.name ||= "default";
  if (!options.tags) {
    options.tags = [];
  }
}
```

Not reported:

{/* good */}

```ts
function connect(options: { port?: number; host: string | null; name?: string; tags?: string[] }) {
  const port = options.port ?? 3000;
  const host = options.host ?? "localhost";
  options.name ??= "default";
  options.tags ??= [];
}

function label(text: string) {
  return text || "untitled"; // never null or undefined
}
```

## Options

| Option                                                   | Default | What it does                                                                                                                                             |
| -------------------------------------------------------- | ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ignoreConditionalTests`                                 | `true`  | Allow `\|\|` in the test of an `if`, a loop, or a ternary, where only true or false matters.                                                             |
| `ignoreTernaryTests`                                     | `false` | Do not report ternaries.                                                                                                                                 |
| `ignoreIfStatements`                                     | `false` | Do not report `if` statements.                                                                                                                           |
| `ignoreMixedLogicalExpressions`                          | `false` | Allow `\|\|` in an expression that also has `&&`.                                                                                                        |
| `ignoreBooleanCoercion`                                  | `false` | Allow `\|\|` inside a call of `Boolean(...)`.                                                                                                            |
| `ignorePrimitives`                                       | `{}`    | Allow `\|\|` when the left side can be one of these: `{ string, number, boolean, bigint }`, each `true` or `false`. `true` means all four.               |
| `allowRuleToRunWithoutStrictNullChecksIKnowWhatIAmDoing` | `false` | Without `strictNullChecks`, the rule cannot tell what can be `null`, and it reports that once for each file. Set this to `true` to turn that report off. |

The test of an `if` is allowed by default:

{/* good */}

```ts
function show(title: string | undefined, subtitle: string) {
  if (title || subtitle) {
    console.log(title, subtitle);
  }
}
```

With `ignoreConditionalTests: false` it is reported:

{/* bad {"options": [{"ignoreConditionalTests": false}]} */}

```ts
function show(title: string | undefined, subtitle: string) {
  if (title || subtitle) {
    console.log(title, subtitle);
  }
}
```

Use `ignorePrimitives: { string: true }` if you want an empty string to get the default too:

{/* good {"options": [{"ignorePrimitives": {"string": true}}]} */}

```ts
function greet(name: string | undefined) {
  return "Hello, " + (name || "stranger");
}
```

A number is still reported with that setting:

{/* bad {"options": [{"ignorePrimitives": {"string": true}}]} */}

```ts
function retries(count: number | undefined) {
  return count || 3;
}
```

With `ignoreMixedLogicalExpressions` the first line is allowed, and with `ignoreBooleanCoercion` the second:

{/* good {"options": [{"ignoreMixedLogicalExpressions": true, "ignoreBooleanCoercion": true}]} */}

```ts
function ready(user: { name: string } | null, guest: { name: string } | null, open: boolean) {
  const allowed = user || (guest && open);
  return Boolean(user || guest) && allowed;
}
```
