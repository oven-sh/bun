---
title: "@typescript-eslint/strict-void-return"
description: "Disallow passing a function that returns a value where a `void` function is expected"
---

TypeScript lets you pass a function that returns something where `() => void` is expected. The caller then drops the result. For an `async` function the dropped result is a promise: nobody awaits it, and if it rejects, nobody catches the error.

The rule checks arguments, assignments, variables with a type, array elements, object and class members, JSX attributes, and `return` statements. A function that returns `undefined` or `never` is fine.

This rule needs type information. Run `bun lint --type-aware`.

## Examples

Reported:

{/* bad {"count": 3} */}

```ts
declare function onChange(listener: (value: string) => void): void;
declare function save(value: string): Promise<void>;
const history: string[] = [];

onChange(async value => {
  await save(value);
});
onChange(value => history.push(value));

const stop: () => void = () => {
  return history.length;
};
```

Not reported:

{/* good */}

```ts
declare function onChange(listener: (value: string) => void): void;
declare function save(value: string): Promise<void>;
const history: string[] = [];

onChange(value => {
  save(value).catch(console.error);
});
onChange(value => {
  history.push(value);
});
onChange(value => void history.push(value));

const stop: () => void = () => {};
```

A method is also reported if the class or interface it comes from declares it as `void`:

{/* bad */}

```ts
interface Plugin {
  setup(): void;
}

class Logger implements Plugin {
  async setup() {
    await Bun.write("log.txt", "");
  }
}
```

## Options

| Option           | Default | What it does                         |
| ---------------- | ------- | ------------------------------------ |
| `allowReturnAny` | `false` | Allow a function that returns `any`. |

`JSON.parse` returns `any`, so this is reported unless `allowReturnAny` is on:

{/* bad */}

```ts
declare function onMessage(listener: (text: string) => void): void;

onMessage(text => JSON.parse(text));
```
