---
title: "unicorn/no-confusing-array-with"
description: "Disallow a negative index and `.length` as the index of `Array#with()`"
---

`array.with(index, value)` returns a copy of the array with one element replaced. A negative index counts from the end, and a reader who does not know that cannot tell which element changes. The array's own `.length` as the index looks like a way to append, but `with()` never makes the array longer. It throws a `RangeError`.

## Examples

Reported:

{/* bad */}

```js
const updated = scores.with(-1, 100);
```

{/* bad */}

```js
const longer = scores.with(scores.length, 100); // throws a RangeError
```

Not reported:

{/* good */}

```js
const updated = scores.with(scores.length - 1, 100);
```

{/* good */}

```js
const longer = [...scores, 100];
```

The rule only sees a number that is written in the call. An index in a variable is not checked:

{/* good */}

```js
const last = -1;
const updated = scores.with(last, 100);
```
