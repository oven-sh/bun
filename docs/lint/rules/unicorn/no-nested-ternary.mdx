---
title: "unicorn/no-nested-ternary"
description: "Disallow deeply nested ternaries, and require parentheses around a ternary in a ternary"
---

In `a ? b : c ? d : e` it is hard to see which `:` belongs to which `?`. This rule allows one ternary inside another if the inner one is in parentheses. A third level is always reported.

`--fix` adds the parentheses. It does not rewrite a third level.

## Examples

Reported:

{/* bad */}

```js
const size = width > 1200 ? "large" : width > 600 ? "medium" : "small";
```

{/* bad */}

```js
const size = width > 1200 ? "large" : width > 600 ? "medium" : width > 300 ? "small" : "tiny";
```

Not reported:

{/* good */}

```js
const size = width > 1200 ? "large" : width > 600 ? "medium" : "small";
```

For more than two levels, use `if` statements:

{/* good */}

```js
function sizeOf(width) {
  if (width > 1200) return "large";
  if (width > 600) return "medium";
  return width > 300 ? "small" : "tiny";
}
```
