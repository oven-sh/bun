---
title: "unicorn/no-this-assignment"
description: "Disallow assigning `this` to a variable"
---

`const self = this` exists to reach the outer `this` from a nested `function`. An arrow function keeps the `this` of the code around it, so the extra variable is not needed.

Only a plain variable is reported. Destructuring (`const { name } = this`) and assigning to a property (`cache.owner = this`) are fine.

## Examples

Reported:

{/* bad */}

```js
class Timer {
  start() {
    const self = this;
    setInterval(function () {
      self.tick();
    }, 1000);
  }
}
```

Not reported:

{/* good */}

```js
class Timer {
  start() {
    setInterval(() => {
      this.tick();
    }, 1000);
  }
}
```

{/* good */}

```js
class Timer {
  start() {
    const { interval } = this;
    registry.current = this;
    setInterval(tick, interval);
  }
}
```
