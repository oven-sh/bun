---
title: "unicorn/no-unreadable-array-destructuring"
description: "Disallow array destructuring that skips two or more values in a row"
---

In `const [,,, year] = parts` you have to count commas to know which element you get, and one comma too many or too few is easy to miss. Read the element by its index instead.

Skipping one value at a time is fine.

## Examples

Reported:

{/* bad {"count": 2} */}

```js
const [, , , year] = match;

function area([, , width, height]) {
  return width * height;
}
```

Not reported:

{/* good */}

```js
const year = match[3];

function area(box) {
  return box[2] * box[3];
}

const [, month] = match;
const [first, , third] = match;
```
