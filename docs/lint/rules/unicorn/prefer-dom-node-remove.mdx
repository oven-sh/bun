---
title: "unicorn/prefer-dom-node-remove"
description: "Require `child.remove()` instead of `parent.removeChild(child)`"
---

`removeChild()` makes you find the parent of a node to remove the node, and it throws if that is not the node's parent. `remove()` is called on the node itself.

`removeChild()` returns the node it removed and `remove()` returns `undefined`. If you need the node afterwards, keep your own reference to it.

The rule does not know types. It reports every call of a method named `removeChild` with one argument that could be a node.

## Examples

Reported:

{/* bad {"count": 2} */}

```js
item.parentNode.removeChild(item);
list.removeChild(list.firstChild);
```

Not reported:

{/* good */}

```js
item.remove();
list.firstChild.remove();
```
