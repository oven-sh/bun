---
title: "unicorn/prefer-modern-dom-apis"
description: "Require `.before()`, `.after()`, `.append()`, `.prepend()` and `.replaceWith()` over older DOM methods"
---

`insertBefore()` and `replaceChild()` need the parent of the node you care about, and the order of their arguments is easy to mix up. `insertAdjacentText()` and `insertAdjacentElement()` take the position as a string. The newer methods are called on the node itself and are named after what they do.

| Reported                                          | Write instead            |
| ------------------------------------------------- | ------------------------ |
| `parent.insertBefore(node, reference)`            | `reference.before(node)` |
| `parent.replaceChild(node, old)`                  | `old.replaceWith(node)`  |
| `element.insertAdjacentText("beforebegin", text)` | `element.before(text)`   |
| `element.insertAdjacentText("afterbegin", text)`  | `element.prepend(text)`  |
| `element.insertAdjacentText("beforeend", text)`   | `element.append(text)`   |
| `element.insertAdjacentText("afterend", text)`    | `element.after(text)`    |

`insertAdjacentElement()` is treated like `insertAdjacentText()`.

## Examples

Reported:

{/* bad {"count": 4} */}

```js
list.insertBefore(item, marker);
list.replaceChild(item, placeholder);
heading.insertAdjacentText("beforeend", "!");
heading.insertAdjacentElement("afterend", note);
```

Not reported:

{/* good */}

```js
marker.before(item);
placeholder.replaceWith(item);
heading.append("!");
heading.after(note);
```

`insertBefore()` and `replaceChild()` are only reported when they are called on a plain variable:

{/* good */}

```js
document.body.insertBefore(banner, main);
```

## When not to use it

`insertBefore()`, `replaceChild()` and `insertAdjacentElement()` return a node, and the newer methods return `undefined`. A call is reported even if its result is used, and then it needs more than a rename.
