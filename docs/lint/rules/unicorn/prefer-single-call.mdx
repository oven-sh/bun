---
title: "unicorn/prefer-single-call"
description: "Require one call instead of several in a row to `push()`, `unshift()`, `classList.add()` and the like"
---

`push()`, `unshift()`, `classList.add()`, `classList.remove()` and `importScripts()` take any number of arguments. Two calls in a row on the same object do what one call does, in more lines.

`--fix` merges the two calls. It does not when there is a comment between them, or when an argument of the second call reads the object, as in `items.push(items.length)`.

## Examples

Reported:

{/* bad {"count": 4} */}

```js
errors.push("name is required");
errors.push("email is not valid");

queue.unshift(second);
queue.unshift(first);

button.classList.add("active");
button.classList.add("large");

importScripts("parser.js");
importScripts("worker-utils.js");
```

Not reported:

{/* good */}

```js
errors.push("name is required", "email is not valid");

queue.unshift(first, second);

button.classList.add("active", "large");

importScripts("parser.js", "worker-utils.js");
```

`push()` on a stream is another method, which takes one chunk. `push()` and `unshift()` are never reported on `stream`, `this`, `this.stream`, `process.stdin`, `process.stdout` and `process.stderr`:

{/* good */}

```js
stream.push(header);
stream.push(body);
```

## Options

| Option   | Default | What it does                                                                             |
| -------- | ------- | ---------------------------------------------------------------------------------------- |
| `ignore` | `[]`    | More `push()` and `unshift()` calls to allow, written as in the code: `"readable.push"`. |

{/* bad */}

```js
readable.push(header);
readable.push(body);
```

{/* good {"options": [{"ignore": ["readable.push"]}]} */}

```js
readable.push(header);
readable.push(body);
```
