---
title: "vitest/consistent-vitest-vi"
description: "Enforce one of `vi` or `vitest` for Vitest's helper object"
---

Vitest exports its helper object under two names, `vi` and `vitest`. They are the same object. Using one name means a search for `vi.mock` finds every mock in the project.

By default the name is `vi`. Both the import and the calls are reported.

`--fix` renames the import and the calls.

## Examples

Reported:

{/* bad {"count": 2} */}

```ts
import { expect, test, vitest } from "vitest";

test("calls the listener", () => {
  const listener = vitest.fn();
  emit("save", listener);
  expect(listener).toHaveBeenCalled();
});
```

Not reported:

{/* good */}

```ts
import { expect, test, vi } from "vitest";

test("calls the listener", () => {
  const listener = vi.fn();
  emit("save", listener);
  expect(listener).toHaveBeenCalled();
});
```

## Options

| Option | Default | What it does                           |
| ------ | ------- | -------------------------------------- |
| `fn`   | `"vi"`  | The name to use: `"vi"` or `"vitest"`. |

{/* bad {"options": [{"fn": "vitest"}]} */}

```ts
import { vi } from "vitest";

vi.useFakeTimers();
```

{/* good {"options": [{"fn": "vitest"}]} */}

```ts
import { vitest } from "vitest";

vitest.useFakeTimers();
```
