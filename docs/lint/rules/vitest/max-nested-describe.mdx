---
title: "vitest/max-nested-describe"
description: "Enforce a maximum depth of nested `describe()` calls"
---

Every level of `describe` can add its own hooks and variables. To understand a test that sits many levels deep, you have to read all the blocks around it, and the test's full name gets long.

By default `describe` blocks can be 5 levels deep. A `describe` at a deeper level is reported. Forms such as `describe.each` count as levels too.

## Examples

These examples use a maximum of 2:

```toml bunfig.toml
[lint.rules]
"vitest/max-nested-describe" = ["error", { max = 2 }]
```

Reported:

{/* bad {"options": [{"max": 2}], "count": 1} */}

```ts
import { describe, expect, test } from "vitest";

describe("cart", () => {
  describe("checkout", () => {
    describe("with a coupon", () => {
      test("lowers the total", () => {
        expect(checkout({ coupon: "SAVE10" }).total).toBe(90);
      });
    });
  });
});
```

Not reported:

{/* good {"options": [{"max": 2}]} */}

```ts
import { describe, expect, test } from "vitest";

describe("cart", () => {
  describe("checkout", () => {
    test("a coupon lowers the total", () => {
      expect(checkout({ coupon: "SAVE10" }).total).toBe(90);
    });
  });
});
```

## Options

| Option | Default | What it does                                                          |
| ------ | ------- | --------------------------------------------------------------------- |
| `max`  | `5`     | The number of levels allowed. With `0`, every `describe` is reported. |

{/* bad {"options": [{"max": 1}]} */}

```ts
import { describe, expect, test } from "vitest";

describe("parse", () => {
  describe.each(["json", "toml"])("%s", format => {
    test("accepts an empty file", () => {
      expect(parse("", format)).toEqual({});
    });
  });
});
```

{/* bad {"options": [{"max": 0}]} */}

```ts
import { describe, expect, test } from "vitest";

describe("parse", () => {
  test("accepts an empty file", () => {
    expect(parse("", "json")).toEqual({});
  });
});
```
