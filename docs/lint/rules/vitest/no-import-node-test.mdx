---
title: "vitest/no-import-node-test"
description: "Disallow importing from `node:test` in a project that uses Vitest"
---

`node:test` exports `test`, `describe` and `it` too, so an editor's auto-import can pick it by mistake. Tests registered with `node:test` are not collected by Vitest, and Vitest reports that the file has no tests.

Only `import` and `export ... from` statements are checked, and only the first one in a file is reported.

A suggestion changes the source to `"vitest"`. `--fix` does not apply suggestions.

## Examples

Reported:

{/* bad */}

```ts
import { describe, it } from "node:test";

describe("slugify", () => {
  it("lowercases the title", () => {});
});
```

A re-export is reported too:

{/* bad */}

```ts
export { test } from "node:test";
```

Not reported:

{/* good */}

```ts
import { describe, it } from "vitest";

describe("slugify", () => {
  it("lowercases the title", () => {});
});
```

## When not to use it

Turn it off for the files that run under Node's own test runner on purpose.
