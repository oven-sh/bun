---
title: "vitest/no-test-prefixes"
description: "Require `.only` and `.skip` instead of the `f` and `x` prefixes"
---

`fit`, `fdescribe`, `xit`, `xtest` and `xdescribe` are Jest's short names for `it.only`, `describe.only`, `it.skip`, `test.skip` and `describe.skip`. Vitest does not export them, so a test file that was moved over from Jest has to use the long names.

`--fix` rewrites the short name to the long one.

## Examples

Reported:

{/* bad {"count": 3} */}

```ts
import { expect } from "vitest";

fit("adds", () => {
  expect(1 + 1).toBe(2);
});

xtest("subtracts", () => {
  expect(3 - 1).toBe(2);
});

xdescribe("division", () => {});
```

Not reported:

{/* good */}

```ts
import { describe, expect, it, test } from "vitest";

it.only("adds", () => {
  expect(1 + 1).toBe(2);
});

test.skip("subtracts", () => {
  expect(3 - 1).toBe(2);
});

describe.skip("division", () => {});
```

What follows the name is kept. This is reported, and `--fix` turns it into `it.skip.each`:

{/* bad */}

```ts
import { expect } from "vitest";

xit.each([1, 2, 3])("%i is positive", n => {
  expect(n).toBeGreaterThan(0);
});
```
