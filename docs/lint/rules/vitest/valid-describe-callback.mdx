---
title: "vitest/valid-describe-callback"
description: "Require `describe` to get a title and a callback with no parameters and no `return`"
---

Vitest calls the callback of `describe` to collect the tests inside it. Without a callback there is nothing to collect. The callback is not a test. It has no `done` to call at the end, and returning the result of `test()` from it does nothing.

The rule reports a `describe` with no title or no callback, a callback that is not a function, a callback with parameters, and a `return` in the callback. An `async` callback is allowed.

## Examples

Reported:

{/* bad */}

```ts
import { describe, test } from "vitest";

describe("cart", done => {
  test("adds an item", () => {});
  done();
});
```

An arrow function with a call as its body returns the result of that call:

{/* bad {"count": 2} */}

```ts
import { describe, test } from "vitest";

describe("cart", () => test("adds an item", () => {}));

describe("checkout", () => {
  return test("adds the tax", () => {});
});
```

{/* bad {"count": 2} */}

```ts
import { describe } from "vitest";

describe("cart");

describe("checkout", "adds the tax");
```

Not reported:

{/* good */}

```ts
import { describe, expect, test } from "vitest";

describe("cart", () => {
  test("adds an item", () => {
    expect(add(item).length).toBe(1);
  });
});

describe("checkout", async () => {
  const rates = await loadRates();

  test("adds the tax", () => {
    expect(total(100, rates)).toBe(108);
  });
});
```

Options can come before the callback, and `describe.todo` needs only a title:

{/* good */}

```ts
import { describe, test } from "vitest";

describe("search", { timeout: 10_000 }, () => {
  test("finds the item", () => {});
});

describe.todo("refunds");
```

The callback of `describe.each` and `describe.for` gets the values of a row, so it can have parameters:

{/* good */}

```ts
import { describe, expect, test } from "vitest";

describe.each([1, 2, 3])("cart with %i items", count => {
  test("counts them", () => {
    expect(fill(count).length).toBe(count);
  });
});

describe.for(["USD", "EUR"])("prices in %s", currency => {
  test("formats the total", () => {
    expect(format(108, currency)).toContain(currency);
  });
});
```

## When not to use it

The rule only looks at what is written. If you share groups of tests between files and pass the callback by name, it is reported as not being a function:

{/* bad */}

```ts
import { describe } from "vitest";
import { cartTests } from "./shared";

describe("cart", cartTests);
```
