---
title: "vitest/warn-todo"
description: "Disallow `.todo` on `test`, `it` and `describe`"
---

`test.todo` stands for a test that nobody has written yet. It checks nothing and the run still passes, so the behavior it names stays untested for as long as the line is forgotten.

## Examples

Reported:

{/* bad {"count": 2} */}

```ts
import { describe, test } from "vitest";

test.todo("refunds the order");

describe.todo("checkout");
```

Not reported:

{/* good */}

```ts
import { expect, test } from "vitest";

test("refunds the order", () => {
  expect(refund(order).total).toBe(0);
});
```

## When not to use it

If you use `.todo` to plan tests and read the list in the test output, this rule only repeats it.
