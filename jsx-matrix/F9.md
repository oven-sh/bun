Fixed in c82be029b22. Each file of an `extends` chain is now named by the real path of the directory that holds it: the directory of the tsconfig.json, or the nearest one above it that contains the file (`TSConfigJSON::name_files_by_real_directory`). A file that `..` reaches outside the linked directory keeps the name of its own directory, and a file under a linked directory above takes the real name of that directory.

Tests: the unit test in `src/resolver/tsconfig_json.rs` has both layouts, and `jsx-tsconfig-react-jsx.test.ts` builds through a link inside the project whose tsconfig.json extends `../tsconfig.json`.
