This is not a change from main. On main (1.4.4-canary.1+f33631841) a lone `--jsx-side-effects` also has no effect, because `Arguments.rs` reads the flag only inside the block for `--jsx-factory`, `--jsx-fragment`, `--jsx-import-source` and `--jsx-runtime`:

```sh
printf 'const unused = <div />;\nconsole.log("x");\n' > a.jsx
bun build --jsx-side-effects --external '*' a.jsx                          # the element is removed
bun build --jsx-side-effects --jsx-runtime=automatic --external '*' a.jsx  # the element stays
```

Main and this branch print the same output for both commands. #46007 makes the flag work alone, so this PR keeps main's behaviour and does not pin it in a test (description, Notes). With `jsx::Sources` that fix is one more arm in `Sources::laid`. `Sources::is_empty` has to keep its meaning: it stands for main's `transform_options.jsx.is_none()` at the place where the working directory's tsconfig.json is laid.
