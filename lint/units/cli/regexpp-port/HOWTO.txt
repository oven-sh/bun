Form of the files (printable ASCII, one case per line):
  # <file> <ecmaVersion or -> <strict 0, 1 or ->            options of the cases after it (literal.txt, test262.txt)
  # pattern <ecmaVersion or -> <strict> <flags -, u, v, uv>  options of the cases after it (patterns.txt)
  <source> <dump>                 the AST
  <source> ! <index> <message>    a RegExpSyntaxError
  <source> !!                     any other error (no case has it)
  <source> +Type:<raw> -Type:<raw> ...    visitor.txt: enter and leave
A string: between double quotes, per UTF-16 unit: \\ and \" for those two, the unit itself from 0x20 to 0x7e, \uXXXX else.
The dump: lib.cjs, function dump. Every node is (Type start end ...); raw and parent are not written: for every node of
every case raw is source.slice(start, end) (the whole source for a RegExpLiteral) and parent is the node that holds it.
