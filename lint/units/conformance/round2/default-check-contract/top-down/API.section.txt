For /workspace/notes/lint/units/conformance/API.md: what the default check makes of `bun --lint` (runner/check_bun_lint.ts).

createSpawnCheck({ command, env, probeTimeoutMs?, probeDirectory?, probed? }) starts `<command> --lint <root files>` in the
current directory of the instance, with BUN_FEATURE_FLAG_EXPERIMENTAL_LINT=1, and reads stderr in the plain format. The probe
runs once (or is handed over as `probed`): a command that runs its operand, refuses the flag or says nothing of a syntax error
is no linter, and every instance is "unavailable". resultOfRun(ended, root, cwd) is the same reading without a process.

Rules. A line whose code is a name that is none of the five of the command and that has a file is a report of a lint rule. It
is no diagnostic of TypeScript: it is left out of the comparison and counted in `rules` by the name of the rule. No option turns
this off.

The guard. An instance of class C counts for the guard when it passes and `rules` is absent: the command wrote nothing and
ended with 0. Near it, and counted apart by the sweep: a pass with `rules` (reports of rules alone), and the cause
`syntax warning` (warnings of the parser and no error; the exit code is 0).

The level. The plain format has no length of a span and no related information: it holds the first section of a baseline
(code, line, column, text and chain of every diagnostic, in order). RunOptions.level says what passes an instance of class E:
"baseline" (absent: every byte) or "first-section". RunResult.level says what was compared: a pass with every byte is
"baseline" whatever was asked, a pass of the first section alone is "first-section" and has headerOnly true, every other
outcome has the level that was asked. expectations.json records "first-section": sweep.ts and conformance.test.ts run at the
level of the lists. The 14 baselines in the pretty form never pass from the plain format. The level goes to "baseline" when
the command hands over lengths and related information (NEEDS N2); lowering it with names in list E is a loss (`--since`).
