### Open question MQ-2, for the maintainers. Not decided here.

Which file of a Bun release carries the notices of `NOTICE.txt` once ported code is in the binary?

- Apache-2.0, section 4(d): a derivative work that is distributed includes a readable copy of the attribution notices
  of the work's NOTICE file, "excluding those notices that do not pertain to any part of the Derivative Works", in a
  NOTICE file, in the source form or documentation, or in a display that the work generates. Section 4(a): every
  recipient gets a copy of the licence.
- `NOTICE.txt` of typescript-go 89d5d5b (48,860 bytes) has the sections DefinitelyTyped, Unicode, Document Object
  Model, Web Background Synchronization and WebGL, and ten dependencies of the Go program: zeebo/xxh3,
  go-json-experiment/json, golang.org/x/sync, x/sys, x/term, x/text, klauspost/cpuid, Microsoft/go-winio,
  mackerelio/go-osstat, parcel-bundler/watcher. `ThirdPartyNoticeText.txt` of TypeScript 5848bc5 (37,824 bytes) has
  the first five.
- What a release holds, read in the scripts (no release archive was opened): the zip is the executable alone
  (`scripts/build/ci.ts:257-259`, `:354-355`); the npm packages are the executable and a `package.json` with
  `license: "MIT"` (`packages/bun-release/scripts/upload-npm.ts:111-136`, `:157-171`). The binary has no command that
  prints the notices of what it links (`bun pm licenses` is about the packages of a project). So no file of a release
  carries a third-party notice today. The npm package `bun-types` ships `docs/`, and with it
  `docs/project/license.mdx` (`packages/bun-types/package.json:22-25`, `scripts/build.ts:30-52`).
- How the repository credits Apache-2.0 code that the binary links: a row with the name and the licence in
  `LICENSE.md` and in the page (simdutf, uSockets, highway, the fork of uWebSockets, parts of Tigerbeetle's IO code;
  `LICENSE.md:33-48`), without a notice text.
- Ported code of typescript-go in the binary at 3110ce85cf: the type productions and the syntax errors in
  `src/js_parser`, and the five files of `src/lint`. No section of `NOTICE.txt` is about that code.
  `src/lint/tspath.rs:572-574` has a case folding table of Unicode 15.0.0 that was made from Go's `unicode` package,
  not from a file of typescript-go.
- What makes the question concrete. The merge of `src/typecheck`: its `stringutil` has the tables of
