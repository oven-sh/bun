### Behaviour: a parse without lint equals main (R2)

```sh
cd /workspace/wt/parser && git status --short -- src test          # nothing: the binary is the commit
SAVE=/workspace/notes/lint/units/parser/round3/proof-behaviour/parity \
  /workspace/tools/lk bash /workspace/notes/lint/units/parser/grammar-diff/parity.sh [[FILL r2-tag]] /workspace/wt/parser/build/release/bun
```

`grammar-diff/parity.sh` runs both binaries over every corpus and compares record by record. It gets no cause
list: one differing record fails the run. A record is one source in one configuration: the output, or the errors
with message, line, column, length, offset, level and notes. The summary is `[[FILL r2-summary: the path of summary.<time>.txt under SAVE/<tag>/]]`.

### Cost: what a parse without lint pays (R3)

```sh
export BUN_RUNTIME_TRANSPILER_CACHE_PATH=0
python3 /workspace/notes/lint/tools/symsizes.py /workspace/base/bun-profile.f4d755a9c
python3 /workspace/notes/lint/tools/symsizes.py /workspace/wt/parser/build/release/bun-profile
stat -c '%s %n' /workspace/base/bun.f4d755a9c /workspace/wt/parser/build/release/bun
/workspace/tools/lk /workspace/notes/lint/tools/cgbench.sh /workspace/base/bun-profile.f4d755a9c [[FILL r3-out]] base 20
/workspace/tools/lk /workspace/notes/lint/tools/cgbench.sh /workspace/wt/parser/build/release/bun-profile [[FILL r3-out]] head 20
python3 /workspace/notes/lint/tools/cgsum.py [[FILL r3-out]]/head.tsx.cg --top 60        # and base, and each group
# the whole report: sizes, machine code by function, counts in both VEX modes, the executed tests by site, the text audit
sh /workspace/notes/lint/units/parser/round3/proof-cost/tools/mkref.sh /tmp/costproof/root /workspace/wt/parser
/workspace/tools/lk sh /workspace/notes/lint/units/parser/round3/proof-cost/top-down-1b/r3cycle.sh ref /tmp/costproof/root/reflink
/workspace/tools/lk sh /workspace/notes/lint/units/parser/round3/proof-cost/top-down-1b/r3report.sh [[FILL r3-out]]
```

`cgbench.sh` runs the transpiler benchmark of this pull request (`bench/snippets/transpiler-typescript.mjs`, fixed
inputs under `/workspace/notes/lint/benchroot`) once per group under cachegrind, 20 passes, JIT off. The counts are
those of the symbols of `bun_js_parser`. `r3report.sh` puts a third binary between the two, the reference: main's
parser text with the sink form, the boxed table and `Metadata::MDot` in the arena, linked into the crates of the
head. Head against reference is the work of this round; reference against base is what the branch changes outside
it, named function by function.
