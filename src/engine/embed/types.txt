# What src/codegen/generate-engine-headers.ts knows of the types in the signatures of api/*.rs.
#   cell     in the heap; a pointer in C++
#   opaque   passed by reference
#   value    passed by value, and represented alike in both languages
#   counted  a counted reference; Ref or RefPtr in C++
#   wrapped  a C++ class around a function pointer
#   mirror   Engine::<name> has the constants of that enum or set of flags
# With `class` or `struct` the C++ type is declared ahead of the functions.
