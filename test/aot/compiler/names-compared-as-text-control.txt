The control of names-compared-as-text.ts: each pattern that the lint finds and each form that it allows.
Nobody compiles this file. It is a .txt so that no formatter and no other lint reads it.
A line that begins with `finds` or `allows` is a mark, and a snippet runs from its mark to the next one.
names-compared-as-text.test.ts hands the lint each snippet alone, as the text of the file at <path>.
  finds <path> <pattern>    exactly one line is reported, under that pattern. If a line ends in `// here`, it is that line
  allows <path> <why>       no line is reported. If the path is the reason, the same lines are reported under an ordinary path
