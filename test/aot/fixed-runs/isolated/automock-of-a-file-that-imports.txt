The original of a mocked module is the file once more, as a second instance: bun test loads it under a key of its own, a compiled run loads it from disk. A mock without a factory, of a file that imports another.
#### deep-automock.test.ts
import { test, vi } from "bun:test";
import { seen } from "./src/user-of-deep";
import * as deep from "./src/deep";
vi.mock("./src/deep");
test("a mock without a factory, of a file that imports another", () => console.error("| CASE deep automock", seen(), typeof deep.twice, vi.isMockFunction(deep.twice), Object.keys(deep).join()));
