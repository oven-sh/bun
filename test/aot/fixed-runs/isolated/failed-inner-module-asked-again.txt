The rethrowing __esm helper of a bundler: every ask for an inner module that failed throws the same error again, also through another inner module.
Over layers the failed module was taken out of the program like a file, and the next ask read a file under its number: a BuildMessage for the kept error.

import "./subject.mjs";
test("subject", () => { expect(1).toBe(1); });

const root = typeof globalThis !== "undefined" ? globalThis : undefined;
var __esm = (fn, res, err) => () => {
  if (fn)
    try {
      res = fn((fn = 0));
    } catch (e) {
      err = [e];
    }
  if (err) throw err[0];
  return res;
};
