A star of a barrel brings a name that node:querystring has too, so the barrel lacks it. While a mock stands for node:querystring the file gives the name. Nobody in the run imports a name of that module: its mock was copied, not asked, and beside a mock under a computed name the barrel lacked the name all the same. The next test file mocks nothing: the name is ambiguous again.
