A CommonJS test file is found in require.cache and does not run again. `bun test --rerun-each=3` loads a test file three times in one realm: each load is a new module of the file, and what the file imports is loaded once.
#### file.test.cjs
const { test } = require("bun:test");
const { state } = require("./counter.cjs");
console.log("| CASE the file runs");
test("counts", () => { state.calls++; console.log("| CASE run", state.calls, require.cache[__filename] === module); });
#### counter.cjs
exports.state = { calls: 0 };
#### package.json
{ "type": "module" }
