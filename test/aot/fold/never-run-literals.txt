# A program holds the regular expression literal /a**/, which the engine refuses, in code that never runs.
# refused: `bun run` prints the literal all the same, so the engine throws a SyntaxError where the file is loaded. A build reports TS100307 for the file.
# loads: `bun run` prints nothing of the literal, and the file loads. A build reports nothing for it.
# never-run-code.test.ts holds plain Bun and `bun check --aot` to the answers, the source test `analysis_fold` holds the model of the compiler to them.
