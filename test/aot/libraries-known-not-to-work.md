## Libraries that are known not to work

These packages work under `bun run` and don't work in an executable. Each does something that `bun compile` rules out on purpose. The table says what that is, with the line of the package that does it, and links to the rule. The versions are the ones that were tried.

Most of them end in the same `TypeError`. It names the object and the property, and its stack trace points to the line in the package. Where the table cuts a `TypeError` short with `...`, it ends like this one:

```txt
TypeError: Cannot assign to Function.prototype.call$0 because built-in objects are read-only in a compiled executable (bun compile differs from bun run here: https://bun.com/docs/compiler/compatibility)
```

The rows about built-in objects apply to [`bun run --aot` and `bun test --aot`](/compiler/debugging#run-under-the-compilers-rules) too, with the same messages. The row of `async-listener` and the rows about the loader and the module cache don't: there your program runs from its source files.

The lines of `sass` and `asciidoctor` belong to a language runtime, not to the package's own code. Other packages that are compiled from Dart with `dart2js`, or from Ruby with Opal, can stop at the same place.

Two old benchmarks add a method to `Object.prototype`. `deltablue` of Octane defines `Object.prototype.inheritsFrom` at the top level of its file, so the build fails with `TS100014`. `string-tagcloud` of SunSpider assigns `Object.prototype.toJSONString` and throws the `TypeError` when it starts.

These change built-in objects too, in ways that are allowed. They load, and change the same members as under `bun run`: `core-js` 3.51.0 (all of it, `core-js/stable` and `core-js/actual`), `@babel/polyfill`, `babel-polyfill`, `react-app-polyfill`, `regenerator-runtime`, `es7-shim`, `reflect-metadata`, `symbol-observable`, `zen-observable`, `colors`, `date-utils`, `temporal-polyfill`, `mockdate`, `timekeeper`, `jest-date-mock`, and the other packages of `es-shims`. So does `sinon`, fake timers included. A `sinon.stub()` of a read-only member, such as `Array.prototype.push`, throws like an assignment.
