# The life of the mock of a module under `bun test --aot`: every step that the run time is known to take. mock-states.test.ts holds the run time against it.
#
#   <mark> <kind of file> <state> (body <status>) > <door> > <kind of file> <state> (body <status>)
#
# The states, as Modules::mockState() computes them:
#   none                                  no mock
#   waits                                 a mock is registered; its factory has not been called; no load has come to the module
#   runs                                  the factory has been called and has not settled
#   in place                              the mock answers for the module, whose body has never run
#   in place while another waits          a second mock waits for the next load
#   in place over a module that has run   later importers get the mock; whoever was linked before keeps the module
#   fills                                 the names of the module hold what the mock gave, and its body never runs
#   laid over                             the body had run; the values of the mock are stored over its own, which are kept
#   failed                                the factory threw or rejected, and an error is kept
#   ended                                 the mock has ended; whoever was linked against it reads it until a load comes to the module
#   ended while another waits            the ended mock still stands, and a new one waits for the next load
#   NONE OF THEM [..]                     what is set together is no state: a fault, or a state that this table lacks
# The doors: the mock call, deferMock, runMock, setMock, willMockModule, didMockModule, exportsBeforeMock, didEndMock, the loader fetches it, runBodyOfRequiredFileAheadOfMock,
#   the mocks of its body wait for the next load, the mocks of its body are laid again (of the module that laid them, not of the mocked one: mock-helper.test.ts).
# And which call meets which state: <kind of file> <state> (body <status>) x <mock.module | vi.mock | jest.mock | vi.doMock | jest.doMock>, <spy | no factory | a file of __mocks__ | a factory that takes the original | a factory>.
# A call that meets no compiled module: no compiled module (the loader holds it | nothing holds it) x <call>, <factory>.
# The marks: `ok` . `?none`: a side is no state . `?end-leaves`: the end of a mock leaves the module mocked . `?new`: appended by BUN_AOT_REWRITE_MOCK_STATES=1, not yet looked at.
