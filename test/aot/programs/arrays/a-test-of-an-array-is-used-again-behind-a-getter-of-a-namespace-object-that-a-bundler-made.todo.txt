With the verifiers on (BUN_FEATURE_FLAG_INTERNAL_FOR_TESTING=1) the build stops: GuardNotAvailable after PlaceTypeTests, in requestHandler. The test of the array's storage in front of the first `matches[matches.length - 1]` is used again by the second one, across the call of the getter `default`. The access is rewritten to GetSlotGetter and a Call that lists no callees (aot/passes/AOTResolveAccessesSlots.cpp becomeCallOfGetterInSlot), so the verifier takes the call for unknown code. Without the verifiers the program builds and prints what plain Bun prints, also where a getter of the same layout really empties, shortens or redefines the array: then the test isn't shared.
