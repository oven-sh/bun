It waits for a rule. Plain Bun gives an Error the own properties originalLine and originalColumn when its stack formatter maps the first frame through a source map. A compiled frame holds its position in the source already and skips the map (src/jsc/bindings/FormatStackTraceForJS.cpp), so an Error made in compiled code has neither property. The list of known differences does not name this: either the formatter defines both for a compiled frame, or the list gets a line and this program a stored output.
