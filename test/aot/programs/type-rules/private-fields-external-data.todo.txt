It waits for a rule. `const data = JSON.parse(..) as { t: number }` stands at module level without an annotation, and `t` holds a string. If such a variable carries the type that the cast wrote, every read of `data.t` throws a TypeError and all five rows print `throws TypeError`. If it holds only a prediction, the rows are plain Bun's: the private fields have inferred types, which test nothing.
