# Triage of CPython's test suite under Bun

Numbers: `score.md` (made by `score.py`), `deficit.py` (the deficit by root cause). This file is written by hand: every way found so far to kill
the interpreter or to make it hang, each with a reproduction of a few lines. The reproductions are tests now:
`../differential/once_crashed/` and `../differential/once_hung/`.

**gone**: no longer happened when this was last gone through (2026-11-03), fixed by other work in the meantime. **Fixed**: fixed as part of this triage.
What `../differential/expected-failures.json` does not list has been fixed since.
