# `new` with arguments, behind a `)` that starts a line. It is reported where its callee ends, and the printer writes that callee without its parentheses. A mapping of the end of the callee of a `new` fixes these.
use(new (c.a().Boom)(1)); :: use(new(c.a().Boom / )(1));
use(new (c.a().Boom)(1)); :: use / ( / new / ( / c / . / a / ( / ) / . / Boom / ) / ( / 1 / ) / ) / ;

# `delete` of an element whose `]` starts a line. It is reported behind the `]`, where nothing is mapped. A mapping behind the `]` fixes these.
delete c[kn][kx]; :: delete c[kn][kx / ];
delete c[kn][kx]; :: delete / c / [ / kn / ] / [ / kx / ] / ;
